Základní terminologie

Tag vs. Element vs. Atribut

Přesné vymezení pojmů, na kterých zkoušející trvají

Otázka u zkoušky

1. Značka (Tag)

Samotný syntaktický text uzavřený ve špičatých závorkách: otevírací značka <p> a ukončovací značka </p>.

2. Element (Prvek)

Celek od počáteční značky přes její obsah až po ukončovací značku:

<p class="lead">Text odstavce</p>

3. Atribut (Attribute)

Doplňující vlastnost zapsaná v otevírací značce jako pár jméno="hodnota" modifikující chování prvku.

Párové vs. Nepárové (Void) elementy

Párové elementy: Mají počáteční i koncovou značku a mohou obsahovat text nebo další vnořené elementy (<div>, <p>, <a>, <table>).

Void elementy (Nepárové): Nemají žádný vnitřní obsah ani koncový tag: <img>, <input>, <br>, <hr>, <meta>, <link>.

Vlastnosti elementů

Klasifikace atributů: Globální vs. data-*

Univerzální vlastnosti dostupné na všech tazích a ukládání klientských metadat

Klíčové globální atributy

  • id="nav": Unikátní identifikátor v celém dokumentu (nesmí se opakovat!). Slouží pro kotvy a JS.
  • class="btn primary": Třída pro stylování a skripty (může se opakovat a jeden element může mít více tříd oddělených mezerou).
  • title="Nápověda": Tooltip zobrazený po najetí myší.
  • lang="cs": Jazyk obsahu elementu.
  • hidden: Skryje element v prohlížeči (obdoba display: none).
  • tabindex="0": Pořadí procházení klávesou Tab (přístupnost).

Vlastní data-* atributy (Custom Data)

Umožňují bezpečně uložit libovolná aplikační data přímo do HTML bez porušení validace:

<div class="course-card" 
     data-course-id="WEB10" 
     data-credits="4"
     data-semester="winter">
</div>

V JavaScriptu jsou okamžitě přístupné přes objekt element.dataset.courseId.

Anatomie šablony

Detailní rozbor kostry HTML5 dokumentu

Význam každého povinného řádku v záhlaví souboru

html • minimální validní kostra 
<!DOCTYPE html>
<html lang="cs">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>EduPortal • Portál VOŠ</title>
</head>
<body>
  <h1>Vítejte ve studijním modulu</h1>
</body>
</html>

Proč nestačí jen napsat <body>?

  • <!DOCTYPE html>: Historický přepínač standardního režimu. Bez něj vykreslovací jádro přepne do Quirks Mode a bude emulovat bugy Internet Exploreru 5.5 z roku 1999!
  • <html lang="cs">: Nezbytné pro vyhledávače a pro čtečky zrakově postižených (jinak bude česky psaný text čten s anglickou fonetikou).
  • <meta charset="UTF-8">: Zabraňuje rozsypání českých diakritických znaků (č, š, ž, ř).
  • <title>: Jediný povinný element v hlavičce <head>. Určuje název záložky a titulek ve výsledcích Google.

Okruh absolutoria č. 4, 3

1. Tag vs. Element

Značka je syntaktický text v lomených závorkách. Element je celá entita od začátku po konec včetně obsahu.

2. Void elementy

Nepárové značky bez obsahu (img, input, meta, link, br, hr). V HTML5 nevyžadují koncové lomítko.

3. Účel entit

Escapování znaků s vyhrazeným významem (&amp;, &lt;, &gt;) a typografická nezlomitelná mezera &nbsp;.

4. Quirks Mode

Chybový režim prohlížeče vyvolaný absencí deklarace <!DOCTYPE html> na prvním řádku.

Typická zkoušková otázka

„Může mít jeden HTML element více různých id nebo více různých tříd?“
Správná odpověď: Více tříd mít MŮŽE (zapisují se oddělené mezerou: class="btn btn-primary large"). Více identifikátorů id však mít NESMÍ! Identifikátor id musí být v rámci celé jedné HTML stránky absolutně unikátní, jinak je kód nevalidní a JavaScriptové metody (např. getElementById) selžou.
