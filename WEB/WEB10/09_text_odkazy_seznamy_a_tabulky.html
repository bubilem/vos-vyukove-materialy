Typografie a sémantika textu

Hierarchie nadpisů a logické formátování

HTML není grafický editor. Každá značka definuje strukturální význam obsahu, nikoliv pouze jeho vizuální velikost či tučnost písma.

Hierarchie nadpisů (<h1> až <h6>)

  • Jedinečné <h1>: Každý dokument má obsahovat právě jedno hlavní <h1> vyjadřující téma stránky (stěžejní pro SEO a screen readery).
  • Žádné přeskakování úrovní: Za <h1> následuje <h2>, vnořené podtémata jsou <h3>. Nikdy nepřeskakujte z <h2> přímo na <h4> jen kvůli tomu, že písmo v prohlížeči vypadá menší.
  • Vizuální velikost řeší CSS: Pokud potřebujete menší text pro <h1>, použijte CSS pravidlo font-size, nikoliv záměnu za <h4>.
Správná sémantická kostra nadpisů
<!-- Správná stromová hierarchie -->
<h1>Výuka webových technologií</h1>
  <h2>Architektura internetu</h2>
    <h3>Klient-server model</h3>
    <h3>Protokol HTTP/HTTPS</h3>
  <h2>Základy jazyka HTML</h2>
    <h3>Struktura dokumentu</h3>

Sémantické vs. prezentační inline značky

Sémantický prvek Prezentační ekvivalent Význam a čtečky obrazovky
<strong> <b> (bold) Vysoká důležitost / varování (hlasový důraz)
<em> <i> (italic) Slovní emfáze / důraz měnící význam věty
<mark> <span class="hl"> Zvýrazněný text (např. výsledky vyhledávání)
<code>, <kbd> <tt> (zastaralé) Zdrojový kód programu, klávesová zkratka
<sub>, <sup> CSS transform Dolní index (H2O), horní index (x2, m2)

Pozor u absolutoria: Prvek <b> a <i> mají v HTML5 specifický okrajový význam (např. jména lodí, taxonomické názvy bez důrazu), ale pro důležitá sdělení se vždy používá <strong> a <em>.

Hypertextová navigace

Hypertextové odkazy (<a>) a URL adresace

Značka <a> (anchor) propojuje světový web. Rozlišování absolutních, relativních a protokolových cest je základem webové navigace.

Typy adresace (href)

  • Absolutní URL: Obsahuje schéma, doménu i cestu: https://example.com/docs/. Využívá se pro externí weby.
  • Relativní k souboru: Vychází z aktuální složky: detail.html, images/logo.png nebo ../about.html.
  • Relativní ke kořeni (root-relative): Začíná lomítkem: /assets/style.css (vždy od kořene domény).
  • Kotevní (fragment): Začíná # a odkazuje na element s id na stejné stránce: #kapitola-2.

Bezpečnostní atributy

Otevření odkazu v novém okně pomocí target="_blank" bez ochrany představuje bezpečnostní zranitelnost (Reverse Tabnabbing).

Bezpečný externí odkaz
<a href="https://externi-web.cz"
   target="_blank"
   rel="noopener noreferrer">
  Dokumentace API
</a>
  • noopener: Brání novému oknu ovládat původní stránku přes window.opener.
  • noreferrer: Zabraňuje odeslání HTTP hlavičky Referer.

Speciální schémata odkazů

  • E-mail (mailto): <a href="mailto:info@skola.cz">
    Otevře výchozího poštovního klienta klienta.
  • Telefon (tel): <a href="tel:+420123456789">
    Umožňuje na mobilních zařízeních okamžité vytočení čísla.
  • Stažení souboru (download): <a href="vyrocni-zprava.pdf" download>
    Vynutí stažení souboru místo jeho zobrazení v prohlížeči.

Struktura dat

Typologie seznamů v HTML: <ul>, <ol> a <dl>

Správná volba seznamu určuje, zda položky mají přísné pořadí, jsou rovnocenné, nebo tvoří slovníkové páry termín-definice.

Neuspořádaný seznam (<ul>)

Používá se, pokud na pořadí prvků nezáleží. Základ navigačních menu a seznamů vlastností.

Navigační menu v <ul>
<ul class="nav-links">
  <li><a href="/">Úvod</a></li>
  <li><a href="/kurzy">Kurzy</a></li>
  <li><a href="/kontakt">Kontakt</a></li>
</ul>

Vizuální odrážky (kolečka, čtverečky) se mění výhradně přes CSS vlastnost list-style-type.

Číslovaný seznam (<ol>)

Značí sekvenci kroků, recepty, algoritmy a žebříčky, kde změna pořadí mění význam sdělení.

HTML5 atributy <ol>
<!-- Číslování od 5 pozpátku -->
<ol start="5" reversed>
  <li>Závěrečné testování</li>
  <li>Sestavení buildu</li>
  <li>Psaní kódu</li>
</ol>

<!-- Typ číslování (a, A, i, I, 1) -->
<ol type="A">
  <li>Možnost první</li>
</ol>

Definiční / popisek (<dl>)

Struktura klíč-hodnota. Skládá se z termínu (<dt>) a jeho popisu/definice (<dd>).

Slovník či metadata v <dl>
<dl>
  <dt>HTML5</dt>
  <dd>Značkovací jazyk pro web.</dd>
  
  <dt>DNS</dt>
  <dd>Systém překladu doménových
      jmen na IP adresy.</dd>
</dl>

Skvělé pro produktové parametry (RAM, CPU), FAQ otázky a odpovědi či slovníky pojmů.

Tabulková data a přístupnost

Struktura tabulek (<table>) a přístupnost

Tabulky slouží výhradně pro dvourozměrná strukturovaná data, nikdy pro layout stránky. Správná sémantika je klíčová pro zrakově postižené.

Anatomie přístupné tabulky

  • <caption>: Titulek tabulky popisující její obsah. Čtečky obrazovky jej čtou jako první informaci.
  • <thead>, <tbody>, <tfoot>: Logické rozdělení na hlavičku sloupců, tělo dat a patičku se souhrny.
  • <th scope="col|row">: Hlavičková buňka. Atribut scope explicitně říká, zda je buňka hlavičkou sloupce nebo řádku.
  • colspan a rowspan: Atributy pro sloučení více buněk vodorovně nebo svisle.
Zákaz tabulkového layoutu: V 90. letech se tabulky používaly k řazení designu stránky do sloupců. Dnes je to hrubá chyba – layout patří výhradně do CSS (Flexbox, CSS Grid).

Příklad plně sémantické tabulky

Kód přístupné tabulky
<table>
  <caption>Přehled zkoušek modulu WEB10</caption>
  <thead>
    <tr>
      <th scope="col">Předmět</th>
      <th scope="col">Termín</th>
      <th scope="col">Kredity</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Architektura</th>
      <td>15. ledna</td>
      <td>4</td>
    </tr>
    <tr>
      <th scope="row">Protokol HTTP</th>
      <td>22. ledna</td>
      <td>4</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th scope="row" colspan="2">Celkem kreditů</th>
      <td>8</td>
    </tr>
  </tfoot>
</table>
06 / 06
Shrnutí & Zkouškový checklist

Klíčové poznatky k absolutoriu (Okruh 4)

Strukturovaný přehled pro rychlé zopakování a obhajobu u zkoušky z webových technologií.

1. Nadpisy h1–h6

Hierarchický strom obsahu. Jedno <h1> na stránku. Nikdy nepřeskakovat úrovně kvůli designu – vizuální velikost řídí CSS.

2. Odkazy a bezpečnost

U target="_blank" vždy doplňovat rel="noopener noreferrer". Rozlišovat relativní a absolutní URL cesty.

3. Výběr seznamu

<ul> pro volné položky, <ol> pro sekvence kroků a postupy, <dl> pro páry termín-definice a metadata.

4. Přístupné tabulky

Pouze pro data, nikdy pro layout. Používat caption, thead/tbody/tfoot a u hlaviček th scope="col|row".

Typická otázka u absolutoria / zkoušky:

„Proč je nepřípustné použít prvek <b> místo <strong>, jaký je mezi nimi sémantický rozdíl a proč by tabulky měly obsahovat atribut scope u tagů <th>?“

Stručná osnova odpovědi: Prvek <b> nese pouze vizuální informaci (tučné písmo) bez přidaného významu pro asistenční technologie. Oproti tomu <strong> nese sémantický význam vysoké důležitosti a nebezpečí, což hlasové čtečky interpretují změnou intonace. U tabulek atribut scope="col" či scope="row" přímo spojuje buňku se záhlavím, takže čtečka při procházení kterékoli buňky čte uživateli její příslušný sloupec či řádek.
