Datový formát

Jazyk XML: Pravidla a syntaxe

Univerzální hierarchický metajazyk pro ukládání a přenos strukturovaných dat

Otázka u zkoušky
xml • ukázka strukturovaných dat 
<?xml version="1.0" encoding="UTF-8"?>
<course id="WEB20">
  <title>Webové technologie II</title>
  <credits>5</credits>
  <description>
    <![CDATA[
      Obsahuje <strong>HTML5</strong> a CSS layouty bez nutnosti escapování znaků & a <.
    ]]>
  </description>
</course>

Přísná pravidla jazyka XML

  • Jediný kořenový prvek: Každý XML dokument musí mít právě jeden kořenový tag obalující veškerý obsah.
  • Case-Sensitive: XML striktně rozlišuje malá a velká písmena (<Title> ≠ <title>).
  • Povinné uzavírání: Každý tag musí být řádně uzavřen (<tag>...</tag> nebo samouzavírací <tag />).
  • Sekce CDATA: Blok <![CDATA[ ... ]]> zabraňuje XML parseru interpretovat znaky < a & uvnitř textu jako začátky nových značek.
Integrita dat

Well-Formed vs. Valid XML (DTD a XSD)

Rozdíl mezi syntaktickou správností a ověřením vůči datovému modelu

Well-Formed (Správně formátovaný)

Dokument vyhovuje obecným syntaktickým pravidlům jazyka XML (má kořenový tag, správné párování a uvozovky u atributů). Pokud XML není Well-Formed, parser okamžitě zastaví zpracování fatální chybou.

Valid (Validní vůči schématu)

Dokument je Well-Formed a navíc splňuje pravidla gramatiky definované v šabloně schématu (povolené názvy tagů, pořadí prvků, povinné atributy a datové typy hodnot).

Kritérium DTD (Document Type Definition) XSD (XML Schema Definition)
Syntaxe Vlastní historická textová syntaxe (mimo XML) Plnohodnotný XML dokument (využívá jmenné prostory)
Datové typy Velmi omezené (vše je v podstatě text / CDATA) Bohatý typový systém (int, decimal, date, regex)
Jmenné prostory Nepodporuje XML Namespaces Plná podpora XML Namespaces
Webová syndikace

Formát RSS 2.0 (Really Simple Syndication)

Distribuce novinek z webu edu_portal přímo do RSS čteček a agregátorů

xml • kanál rss 2.0 
<?xml version="1.0" encoding="UTF-8"?>
<rss version="2.0">
  <channel>
    <title>EduPortal • Výukové novinky</title>
    <link>https://edu-portal.cz</link>
    <description>Aktuální články o webových technologiích</description>
    <language>cs</language>

    <item>
      <title>Principy kaskády a specificity v CSS</title>
      <link>https://edu-portal.cz/clanky/css-kaskada</link>
      <guid isPermaLink="true">https://edu-portal.cz/clanky/css-kaskada</guid>
      <pubDate>Wed, 16 Sep 2026 10:00:00 +0200</pubDate>
      <description>Detailní průvodce výpočtem specificity...</description>
    </item>
  </channel>
</rss>

Struktura RSS 2.0

  • Kořen <rss version="2.0">: Obaluje kanál <channel>.
  • Povinné elementy kanálu: <title>, <link> a <description>.
  • Položka <item>: Reprezentuje jeden samostatný článek nebo epizodu podcastu (může mít i multimediální přílohu <enclosure>).
  • guid: Globálně unikátní identifikátor článku (zabraňuje duplicitnímu načtení ve čtečce).
  • Formát data pubDate: Striktní formát standardu RFC 822 (např. Wed, 16 Sep 2026 10:00:00 +0200).
Moderní standard

Formát Atom (IETF RFC 4287) vs. RSS

Proč vznikl Atom a v čem překonává nedostatky RSS 2.0

xml • kanál atom (rfc 4287) 
<?xml version="1.0" encoding="UTF-8"?>
<feed xmlns="http://www.w3.org/2005/Atom">
  <title>EduPortal Atom Feed</title>
  <id>urn:uuid:60a76c80-d399-11d9-b93C-0003939e0af6</id>
  <updated>2026-09-16T10:00:00Z</updated>
  <link href="https://edu-portal.cz"/>

  <entry>
    <title>Responzivní design a Mobile-First</title>
    <id>https://edu-portal.cz/clanky/rwd</id>
    <updated>2026-09-16T10:00:00Z</updated>
    <summary>Praktický přehled media queries v CSS...</summary>
    <link href="https://edu-portal.cz/clanky/rwd"/>
  </entry>
</feed>

Výhody Atomu oproti RSS 2.0

  • Standardizováno v IETF: Atom je oficiální internetový RFC standard, zatímco specifikace RSS 2.0 byla "zmrazena" a obsahuje nejednoznačnosti.
  • Mezinárodní formát data: Atom striktně používá standardní ISO 8601 (např. 2026-09-16T10:00:00Z) bez zmatků se zkratkami zón.
  • Povinný unikátní identifikátor (id): Každý kanál i každá položka <entry> musí mít trvalý URI/URN identifikátor.
  • Propojení s HTML: Automatická detekce prohlížečem:
    <link rel="alternate" type="application/atom+xml" href="/atom.xml">

Okruhy absolutoria 7–13

1. Sémantika & DOM (Okruh 7)

Struktura HTML5 dokumentu, sekční elementy (header, nav, main, article), objektový model stromu DOM a vznik Render Tree.

2. CSS & Kaskáda (Okruhy 8–9)

Výpočet specificity (A:B:C:D), mechanismus dědičnosti, stromové kombinátory (>, +, ~) a pseudotřídy :nth-child().

3. Box Model & Layouty (Okruhy 10–11)

border-box standard, režimy pozicování (sticky, absolute, z-index), jednorozměrný Flexbox a 2D mřížka CSS Grid.

4. Preprocesory & Syndikace (Okruhy 12–13)

Proměnné a vnořování v Sass/Less, mixiny a partials, pravidla XML a rozdíly formátů RSS 2.0 vs. Atom.

Při ústní zkoušce vždy propojte teoretický výklad s praktickou ukázkou na kódu: od sémantického značkování stránky přes pravidla kaskády až po moderní responzivní layout a datovou syndikaci. Všechny prezentace modulu WEB20 máte k dispozici 100% offline v tomto výukovém balíčku!
