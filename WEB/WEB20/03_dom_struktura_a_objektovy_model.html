Jak vzniká DOM: Zpracování HTML kódu

Čtyři fáze transformace: Bajty → Znaky → Tokeny → Uzly → DOM strom

Otázka u zkoušky

Když prohlížeč přijme HTML odpověď ze sítě, nepracuje přímo s textem, ale provádí systematický parsing:

1. Konverze (Bytes)

Surové bajty 3C 68 74 6D 6C... jsou podle kódování (UTF-8) převedeny na textové znaky.

2. Tokenizace

Lexikální analyzátor identifikuje HTML značky a vytváří tokeny: StartTag: html, Tag: body, EndTag: p.

3. Tvorba uzlů (Nodes)

Tokeny jsou transformovány na konkrétní objekty v paměti reprezentující uzly se svými vlastnostmi a metodami.

4. Sestavení DOM

Protože se HTML tagy do sebe vnořují, uzly jsou propojeny do stromové hierarchie rodič-potomek.

Definice DOM pro zkoušku

DOM (Document Object Model) je programové objektové rozhraní (API) reprezentující strukturovaný HTML nebo XML dokument jako strom objektů (uzlů), které lze dynamicky číst a modifikovat skripty.

Typologie objektů

Typy uzlů a rozdíl mezi Node a Element

Hierarchie rozhraní: Document, Element, Text, Attribute a Comment

Typ uzlu nodeType nodeName Příklad v HTML kódu
ELEMENT_NODE 1 Název tagu velkými písmeny ("DIV", "P") <p class="lead">...</p>
ATTRIBUTE_NODE 2 Název atributu ("class", "id") class="lead"
TEXT_NODE 3 "#text" Vlastní text uvnitř tagu i bílé znaky a odřádkování
COMMENT_NODE 8 "#comment" <!-- Poznámka k layoutu -->
DOCUMENT_NODE 9 "#document" Kořenový objekt celé stránky (window.document)
Pozor na bílé znaky v DOM!

Každé odřádkování a mezera mezi HTML tagy vytváří v DOM stromu samostatný TEXT_NODE! Proto vlastnost childNodes obsahuje více položek než children (která vrací pouze potomky typu Element).

Rozhraní Node vs. Element pro bezpečnou orientaci v DOM

Navigace přes uzly (včetně mezer)

  • parentNode: Rodičovský uzel.
  • childNodes: NodeList všech potomků (elementy, texty i komentáře).
  • firstChild / lastChild: První / poslední uzel.
  • nextSibling / previousSibling: Sousedící uzly na stejné úrovni.

Navigace čistě po elementech (Doporučeno)

  • parentElement: Rodičovský HTML element.
  • children: HTMLCollection obsahující výhradně tagy (elementy).
  • firstElementChild / lastElementChild: První / poslední tag.
  • nextElementSibling / previousElementSibling: Následující / předchozí tag.
Vykreslování na obrazovku

DOM + CSSOM = Render Tree

Proč to, co je v DOMu, nemusí být na obrazovce (display: none vs. visibility: hidden)

1. DOM Tree

Reprezentuje kompletní sémantický obsah a strukturu HTML dokumentu bez ohledu na to, zda má být vidět.

2. CSSOM Tree

Strom kaskádových stylů (CSS Object Model). Obsahuje pravidla pro každý selektor a vypočtené hodnoty vlastností.

3. Render Tree

Kombinace DOM a CSSOM. Obsahuje pouze viditelné uzly se všemi aplikovanými styly, podle nichž probíhá Layout (Reflow) a Paint.

Otázka k absolutoriu: display: none vs. visibility: hidden
  • display: none → Element v DOM existuje, ale je zcela vyřazen z Render Tree. Nezabírá v layoutu žádné místo.
  • visibility: hidden → Element je součástí Render Tree. Vykreslí se jako neviditelná obdélníková plocha a zachovává své rozměry v layoutu.
  • <head>, <script>, <meta> → Vždy v DOM, nikdy v Render Tree.

Okruh absolutoria č. 7

1. Co je to DOM

Objektová stromová reprezentace dokumentu v paměti vytvořená prohlížečem při parsování HTML.

2. Rozdíl Node vs. Element

Element je pouze jeden z podtypů uzlu (nodeType 1). Uzel může být i text (nodeType 3), komentář (8) či dokument (9).

3. Vznik Render Tree

Spojením DOM (struktura) a CSSOM (styly). Zahrnuje pouze vizuálně vykreslitelné prvky.

4. Reflow a Repaint

Změna geometrie v DOM vyvolá náročný výpočet rozměrů (Reflow/Layout) a následné přemalování pixelů (Repaint).

Typická zkoušková otázka

„Je HTML zdrojový kód zobrazený přes 'Zobrazit zdrojový kód stránky' totožný s tím, co vidíme v panelu Elements vývojářských nástrojů?“
Správná odpověď: Není! Zobrazení zdrojového kódu (Ctrl+U) je statický text stažený ze serveru. Panel Elements ve vývojářských nástrojích (F12) zobrazuje živý DOM strom, který mohl být opraven chybovým parserem prohlížeče a dynamicky pozměněn skripty.
