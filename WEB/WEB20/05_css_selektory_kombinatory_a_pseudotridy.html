Základní stavební kameny

Typové selektory, seskupování, třídy a ID

Elementární výběr prvků v DOM stromu a způsoby kombinování bez hierarchických vazeb

Otázka u zkoušky

1. Typový selektor (Tag) & Univerzální selektor (*)

Cílí přímo na název HTML elementu bez ohledu na jeho třídy či atributy:

  • p { line-height: 1.6; } – ovlivní všechny odstavce na stránce.
  • * { box-sizing: border-box; } – univerzální selektor vybere všechny existující uzly v DOM.
  • Specificita: Tag má váhu (0, 0, 1), univerzální selektor * má váhu (0, 0, 0).

2. Vícenásobný selektor / Seskupování (Čárka ,)

Logická operace OR (NEBO). Sdružuje více selektorů pod identický blok vlastností bez duplikace kódu (princip DRY):

h1, h2, h3, .heading-lead { font-family: var(--font-display); }

Pozor na úskalí: V klasickém CSS zneplatní jediný neznámý selektor v seznamu celý blok pravidel!

3. Třídní selektory (.class) a jejich řetězení

Znovupoužitelné identifikátory komponent nezávislé na typu HTML značky:

  • .btn { padding: 0.5rem 1rem; } – specificita (0, 1, 0).
  • Řetězení tříd bez mezery: button.btn.btn-primary.is-active reprezentuje logické AND (A ZÁROVEŇ). Prvek musí být tagem <button> a mít současně všechny 3 třídy! Specificita se sčítá: (0, 3, 1).

4. Selektor identifikátoru (#id)

Cílí na unikátní element s daným HTML atributem id="app":

  • #main-nav { position: sticky; } – extrémní specificita (1, 0, 0)!
  • Architektonické pravidlo VOŠ: Identifikátory se v moderním CSS (BEM, utility-first) pro stylování nepoužívají, protože „betonují“ kaskádu a nelze je jednoduše přebít třídami. ID je vyhrazeno pro kotevní odkazy v URL a JavaScriptové háčky.
Klíčový syntaktický kontrast: Mezera vs. Bez mezery

Zápis .btn.active (bez mezery) znamená „element mající obě třídy zároveň“ (AND). Oproti tomu zápis .btn .active (s mezerou) znamená „element .active zanořený kdekoliv uvnitř .btn“ (potomek)!

Vztahy v DOM stromu

Stromové kombinátory: Potomci vs. Sourozenci

Hierarchické operátory vyjadřující polohu a vzdálenost prvků v DOM stromu

Klíčové téma

1. Libovolný potomek (Mezera: A B)

Vybere element B, který je kdekoliv zanořen uvnitř elementu A (děti, vnoučata, libovolná hloubka):

.article-body p { margin-bottom: 1rem; }

Riziko: Pravidlo nechtěně prosákne i do vnořených komponent (např. odstavce v kartách citací uvnitř článku).

2. Přímý potomek / Dítě (A > B)

Vybere element B, pouze pokud je element A jeho bezprostředním rodičem (rodič → dítě):

ul.menu-list > li { border-bottom: 1px solid #334; }

Zajišťuje striktní izolaci: nepoužije se na položky <li> ve vnořených podmenu <ul>.

3. Sousední sourozenec (A + B)

Vybere element B, který leží na stejné úrovni a následuje bezprostředně ihned za elementem A:

h2 + p { font-size: 1.2rem; color: var(--accent); } /* Perex */

Využití pro vertikální rytmus: .form-group + .form-group { margin-top: 1rem; } přidá mezeru pouze mezi dvěma poli.

4. Obecný sourozenec (A ~ B)

Vybere jakýkoliv element B, který sdílí stejného rodiče a nachází se kdekoliv za elementem A:

h2 ~ p { line-height: 1.6; }

Základ pro CSS interaktivitu: input:checked ~ .accordion-body { display: block; }.

html vs css • ukázka interpretace kombinátorů v DOM 
<!-- DOM Struktura: -->
<section class="post">
  <h2>Titulek</h2>
  <p>Perex (zasáhne: post p, post > p, h2 + p, h2 ~ p)</p>
  <p>Druhý odstavec (zasáhne: post p, post > p, h2 ~ p; NEZASÁHNE: h2 + p)</p>
  <div class="box"><p>Vnořený (zasáhne: post p; NEZASÁHNE: post > p)</p></div>
</section>
Atributové filtry

Atributové selektory a regulární vzory

Přesné zacílení prvků na základě přítomnosti, hodnoty nebo podřetězce v HTML atributech

Otázka u zkoušky
Selektor Podmínka shody Praktická aplikace (edu_portal)
[disabled] Element má daný atribut definován bez ohledu na hodnotu. button[disabled] { opacity: 0.5; cursor: not-allowed; }
[type="email"] Přesná rovnost celé hodnoty atributu. Cílení na specifický typ formulářového pole bez dodatečné třídy.
[href^="https://"] Hodnota atributu začíná zadaným řetězcem. Zabezpečené externí odkazy (přidání ikonky zámku či šipky ven).
[href$=".pdf"] Hodnota atributu končí zadaným řetězcem. Automatická indikace stahovatelného dokumentu PDF za odkazem.
[class*="col-"] Hodnota atributu obsahuje kdekoliv uvnitř podřetězec. Společné stylování mřížkových sloupců: col-sm-4, col-lg-6.
[data-tags~="web"] Obsahuje slovo v seznamu odděleném mezerami (jako třídy). Filtrování položek v katalogu kurzů podle klíčových slov.
[lang|="cs"] Rovná se přesně cs nebo začíná cs- (např. cs-CZ). Lokalizační a typografická pravidla pro konkrétní jazyk.
Modifikátor i: Ignorování velikosti písmen

Příznak i na konci závorky ignoruje case: a[href$=".pdf" i] zacílí na .pdf i .PDF. Příznak s naopak vynucuje striktní shodu (case-sensitive).

Moderní praxe: Data-atributy a ARIA stavy

Místo přepínání tříd stylujte přímo stavové atributy: [aria-expanded="true"] pro otevřené dropdowny nebo [data-state="active"] pro taby.

Dynamické stavy rozhraní

Stavové pseudotřídy: Uživatelská interakce a formuláře

Reakce na chování uživatele a interní stavy formulářových prvků v prohlížeči

UX & Přístupnost

1. Uživatelská interakce

  • :hover: Najetí ukazatelem myši na element.
  • :active: Okamžik fyzického stisku myši či dotyku.
  • :focus: Prvek získal zaměření (klikem či klávesou Tab).
  • :focus-visible: Klíč k přístupnosti (WCAG). Zobrazí rámeček POUZE při navigaci z klávesnice, při kliku myší zůstává skrytý!
  • :focus-within: Aktivuje se na rodiči, pokud má fokus on sám nebo kterýkoliv jeho potomek (např. zvýraznění celé formulářové karty).

2. Formulářové stavy

  • :checked: Aktivní checkbox, radio button či zvolený option.
  • :disabled / :enabled: Vypnuté vs. přístupné pole.
  • :required / :optional: Pole s atributem required.
  • :valid / :invalid: Dynamická reakce na HTML5 validaci (např. regex pattern nebo e-mail).
  • :placeholder-shown: Detekuje, zda uživatel ještě nic nenapsal (technika pro plovoucí labely).

3. Navigace & DOM stavy

  • :link / :visited: Nenavštívený vs. navštívený odkaz (kvůli soukromí lze měnit pouze barvy).
  • :target: Cílí na prvek, jehož id odpovídá aktuálnímu hashi v URL adrese (#modal-1). Umožňuje vytvářet čisté CSS modály, záložky a lightbox bez JS!
  • Specificita pseudotřídy: Vždy má váhu třídy (0, 1, 0).
css • ukázka moderního přístupného formulářového pole 
/* Zvýraznění celého kontejneru při psaní do kteréhokoliv vnořeného inputu */
.form-card:focus-within {
  border-color: var(--accent);
  box-shadow: 0 0 0 3px rgba(56, 189, 248, 0.2);
}

/* Přístupný focus outline pouze pro klávesnici */
button:focus-visible {
  outline: 2px solid var(--accent);
  outline-offset: 2px;
}
Strukturální pozicování

Strukturální pseudotřídy a počítání v DOM stromu

Matematický vzorec An + B a zásadní rozdíl mezi pořadím potomka a pořadím typu

Otázka u zkoušky

Vzorec :nth-child(An + B)

Umožňuje pokročilé matematické filtrování v seznamech a tabulkách:

  • :first-child / :last-child: První / poslední potomek rodiče.
  • :nth-child(odd) = (2n + 1): Každý lichý řádek (zebra tabulky).
  • :nth-child(even) = (2n): Každý sudý řádek tabulky.
  • :nth-child(3n): Každý třetí prvek (3, 6, 9...).
  • :nth-child(n + 4): Všechny prvky od 4. výše (oříznutí přebytků).
  • :nth-child(-n + 3): Pouze první 3 prvky v seznamu.

Novinka v CSS4: Filtrování se selektorem

Syntaktické rozšíření :nth-child(An + B of .selector):

.list-item:nth-child(2 of .featured)

Vybere druhý prvek, který má třídu .featured, i když jsou mezi položkami jiné elementy!

Rozdíl: :nth-child vs. :nth-of-type

Nejčastější zdroj chyb u začátečníků a oblíbený zkušební chyták:

  • :nth-child(n): Počítá všechny sourozence bez rozdílu tagu. Podmínka zní: „Být n-tým potomkem rodiče A ZÁROVEŇ odpovídat selektoru“.
  • :nth-of-type(n): Vytvoří separátní počítadlo pouze pro daný konkrétní tag.
  • :only-child vs. :only-of-type: Jedináček v rodiči bez jiných dětí vs. jediný svého tagu.
  • :empty: Element nemá žádné potomky ani bílé znaky.
  • :root: Kořenový element dokumentu (<html>), nosič CSS proměnných.
Chyták zkoušejícího u tabule

Mějme: <section><h2>A</h2><p>B</p></section>.
Otázka: Obarví pravidlo p:first-child { color: red; } text B?
NEOBARVÍ! Prvním potomkem sekce je totiž <h2>. Pro obarvení musíte použít p:first-of-type nebo h2 + p.

Moderní CSS Selectors Level 4

Funkcionální selektory: :is(), :where(), :not() a :has()

Zkrácení zápisu, nulování specificity a revoluční rodičovský selektor bez nutnosti JavaScriptu

Pokročilé CSS

1. :is(...) • Sdružovací selektor

Dramaticky zjednodušuje zápis zanořených pravidel:

:is(header, main, footer) :is(h1, h2, h3) { color: #fff; }
  • Nahrazuje 9 zdlouhavých kombinací.
  • Forgiving Selector List: Pokud je jeden ze selektorů v závorce neplatný, prohlížeč jej zahodí, ale zbytek pravidel normálně funguje!
  • Specificita: Přebírá nejvyšší specificitu ze všech argumentů v závorce.

2. :where(...) • Nulová specificita (0, 0, 0)

Syntakticky identický s :is(), ale má VŽDY nulovou specificitu!

:where(button, input, select) { border-radius: 4px; }
  • Svatý grál pro tvůrce UI knihoven a CSS resetů.
  • Jakákoliv pozdější třída vývojáře (.custom-btn) toto pravidlo hladce přebije bez použití !important.

3. :not(...) • Logická negace

Cílí na prvky, které nesplňují zadanou podmínku:

button:not(.btn-primary, :disabled) { background: #555; }

V moderním CSS přijímá více argumentů oddělených čárkou.

4. :has(...) • Rodičovský & Relační selektor

Největší revoluce v CSS za posledních 15 let. Umožňuje stylovat element na základě jeho potomků nebo sourozenců:

  • .card:has(img) { grid-template-columns: 1fr 1fr; } → styluje kartu, pokud uvnitř obsahuje obrázek!
  • form:has(input:invalid) button[type="submit"] { opacity: 0.5; pointer-events: none; } → zablokuje tlačítko, má-li formulář nevalidní pole.
  • h2:has(+ p.lead) { margin-bottom: 0.5rem; } → nadpis, za nímž ihned následuje perex.
Proč :has() eliminuje nutnost JavaScriptu?

Dříve musel frontendový vývojář psát JavaScriptové listenery, které přidávaly pomocné třídy typu .card--has-media nebo .form--is-dirty. S pseudotřídou :has() reaguje kaskáda na stav vnořeného DOM stromu plně nativně!

Virtuální uzly Render Tree

Pseudoelementy: ::before, ::after a generovaný obsah

Rozdíl mezi pseudotřídou (stav prvku) a pseudoelementem (nově generovaný sub-element)

Generovaný obsah
css • dekorační akcent a vlastní odrážka 
.card {
  position: relative;
  padding-left: 1.5rem;
}

/* Generovaný akcentní proužek před obsahem */
.card::before {
  content: "";             /* Povinné! */
  position: absolute;
  top: 0;
  left: 0;
  width: 4px;
  height: 100%;
  background: var(--accent);
}

/* Styl uživatelského označení textu */
::selection {
  background: #38bdf8;
  color: #0f172a;
}

Klíčové zásady pseudoelementů

  • Syntaktická konvence: Od CSS3 se pseudoelementy zapisují se dvěma dvojtečkami (::before, ::after, ::marker, ::selection), zatímco pseudotřídy s jednou (:hover). Prohlížeče z důvodu zpětné kompatibility tolerují u :before i jednu, ale na VOŠ píšeme dvě!
  • Vlastnost content: Bez uvedení content: "" se pseudoelement v Render Tree vůbec nevygeneruje.
  • Poloha v DOM: ::before je vložen jako první potomek uvnitř cílového elementu, ::after jako poslední potomek uvnitř.
  • Kde je nelze použít: Nelze aplikovat na nepárové nahrazované elementy bez potomků (jako <img> nebo <input>).
  • Další užitečné: ::marker (odrážka <li>), ::placeholder (zástupný text), ::first-letter (typografická iniciála).
JavaScript & DOM API

Výběr z DOM v JavaScriptu a algoritmus vyhodnocování

Metody querySelector, closest a princip Right-to-Left vyhodnocování v jádře prohlížeče

Architektura & Výkon

1. DOM Selectors API v moderním JS

JavaScript využívá stejný vyhledávací engine jako kaskádové styly:

  • document.querySelector(sel): Vrátí první odpovídající element (nebo null).
  • document.querySelectorAll(sel): Vrátí statický NodeList všech shodných prvků (nepřepočítává se živě).
  • element.closest(sel): Opačný querySelector. Prochází DOM stromem nahoru k rodičům a najde nejbližšího předka vyhovujícího selektoru (např. klik na ikonu → najdi obalující .card).
  • element.matches(sel): Vrací true/false. Pilíř pro Event Delegation (odchytávání událostí na společném předkovi).

2. Jak prohlížeč vyhodnocuje: Right-to-Left (RTL)

CSS parser v renderovacím enginu (Blink, Gecko, WebKit) vyhodnocuje selektory zprava doleva:

header .nav-list > li a[href]
  • Prvek zcela vpravo je tzv. Key Selector (zde a[href]).
  • Prohlížeč nejprve najde všechny odkazy na celé stránce a teprve pro ně stoupá DOM stromem nahoru a ověřuje, zda leží v li, .nav-list a header.
  • Doporučení pro výkon: Vyhněte se příliš obecným klíčovým selektorům (např. .sidebar * nebo div div span), které nutí engine zbytečně testovat tisíce DOM uzlů při každém překreslení.
javascript • ukázka Event Delegation s matches() a closest() 
// Efektivní odchytávání kliknutí na tlačítkách v dynamickém seznamu
document.querySelector('.data-grid').addEventListener('click', (e) => {
  const btn = e.target.closest('button[data-action]');
  if (!btn) return; // Klik mimo akční tlačítko

  const row = btn.closest('tr');
  const action = btn.dataset.action;
  console.log(`Akce ${action} na řádku ID:`, row.dataset.id);
});

Okruh absolutoria č. 9

1. Základní selektory & Vazby

Typové tagy, třídy, identifikátory a rozdíl mezi logickým OR (čárka ,) a logickým AND (řetězení tříd .a.b bez mezery).

2. Stromové kombinátory

Přesný rozdíl mezi libovolným potomkem (mezera), přímým dítětem (>), sousedem (+) a obecným sourozencem (~).

3. Atributy & Pseudotřídy

Zástupné znaky ^=, $=, *=, kalkulace :nth-child(An+B) vs. :nth-of-type() a stavy :focus-visible / :focus-within.

4. Moderní CSS4 & Pseudoelementy

Rozdíl specificity mezi :is() (max) a :where() (0), revoluce selektoru :has() a princip ::before/::after s content.

Chyták č. 1: Specificita funkcionálních selektorů

Jaká je specificita pravidla :where(#header, .nav) a?
Odpověď: Pouze (0, 0, 1)! Závorka :where() má totiž vždy nulovou váhu, započte se jen koncový tag a. Pokud by tam bylo :is(), váha by byla (1, 0, 1)!

Chyták č. 2: Pseudotřída vs. Pseudoelement

Pseudotřída (:hover, :first-child) vybírá celý existující element v určitém stavu (váha 0-1-0). Pseudoelement (::before, ::first-line) vytváří virtuální sub-uzel a má váhu běžného tagu (0-0-1).
