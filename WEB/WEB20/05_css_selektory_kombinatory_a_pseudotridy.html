Filtrování podle HTML atributů

Síla zástupných znaků (^=, $=, *=) bez nutnosti vytvářet pomocné třídy

Otázka u zkoušky
Selektor Význam podmínky Praktická ukázka pro edu_portal
[target] Element má daný atribut definován bez ohledu na hodnotu. a[target] { color: var(--accent-amber); }
[type="email"] Přesná rovnost celé hodnoty atributu. Cílení specificky na e-mailové pole formuláře.
[href^="https://"] Hodnota atributu začíná zadaným řetězcem. Obarvení nebo přidání ikonky pro zabezpečené externí odkazy.
[href$=".pdf"] Hodnota atributu končí zadaným řetězcem. Automatická indikace stahovatelného souboru PDF za odkazem.
[class*="btn-"] Hodnota atributu obsahuje kdekoliv uvnitř podřetězec. Stylování všech tlačítek: btn-primary, btn-danger.
Tip: Ignorování velikosti písmen

Přidáním příznaku i na konec hranatých závorek ignorujete velikost písmen: a[href$=".pdf" i] zacílí i na soubory s koncovkou .PDF.

Vztahy v DOM stromu

Stromové kombinátory: Potomci vs. Sourozenci

Čtyři základní operátory pro hierarchické zacílení

1. Libovolný potomek (Mezera: A B)

Vybere element B, který je kdekoliv zanořen uvnitř elementu A (děti, vnoučata atd.):

.article-body p

2. Přímý potomek / dítě (A > B)

Vybere element B, pouze pokud je jeho bezprostředním rodičem element A (žádné hlubší zanoření):

.menu-list > li

3. Sousední sourozenec (A + B)

Vybere element B, který leží na stejné úrovni a následuje bezprostředně ihned za elementem A:

h2 + p { font-size: 1.2rem; } /* Perex článku */

4. Obecný sourozenec (A ~ B)

Vybere jakýkoliv element B, který má stejného rodiče a nachází se kdekoliv za elementem A:

h2 ~ p
Dynamické chování

Pseudotřídy: Uživatelské stavy a :nth-child()

Reakce na interakci a strukturální počítání položek v seznamech

Stavové pseudotřídy (UX & Formuláře)

  • :hover: Najetí kurzoru myši.
  • :focus: Zaměření prvku klávesnicí nebo kliknutím.
  • :focus-visible: Zobrazí rámeček pouze při navigaci klávesnicí (Tab), nikoliv při kliku myší!
  • :active: Okamžik stisknutí tlačítka myši.
  • :checked, :disabled, :valid: Reflexe stavu formulářového pole.

Strukturální pseudotřída :nth-child(An + B)

Umožňuje pruhovat tabulky, generovat mřížky nebo stylovat konkrétní položky:

  • :first-child / :last-child: První / poslední prvek.
  • :nth-child(odd) nebo (2n + 1): Každý lichý řádek.
  • :nth-child(even) nebo (2n): Každý sudý řádek.
  • :nth-child(3n): Každý třetí sloupec v katalogu kurzů.
  • :not(.featured): Negace – vybere prvky bez dané třídy.
Generovaný obsah

Pseudoelementy: ::before, ::after a grafické efekty

Rozdíl mezi pseudotřídou (jedna dvojtečka) a pseudoelementem (dvě dvojtečky)

css • dekorační ::before a ::after 
.card {
  position: relative;
  padding: 1.5rem;
}

/* Vytvoření dekoračního akcentního proužku */
.card::before {
  content: "";        /* Povinná vlastnost! */
  position: absolute;
  top: 0;
  left: 0;
  width: 4px;
  height: 100%;
  background: #06b6d4;
}

Klíčové zásady pseudoelementů

  • Syntaktická konvence: Od CSS3 se pseudoelementy zapisují se dvěma dvojtečkami (::before, ::after, ::placeholder, ::selection), zatímco pseudotřídy s jednou (:hover).
  • Povinná vlastnost content: Bez uvedení vlastnosti content: "" se pseudoelement v Render Tree vůbec nevytvoří!
  • Generování do DOM: ::before se vloží jako první potomek cílového elementu, ::after jako poslední potomek.
  • Kde nelze použít: Nelze aplikovat na nepárové nahrazované elementy (jako <img> nebo <input>).

Shrnutí & Požadavky k absolutoriu

Co musíte bezpečně ovládat z okruhu č. 9 (Selektory a pseudotřídy)

Okruh absolutoria č. 9

1. Kombinátory

Přesný rozdíl mezi mezerou (libovolný potomek), > (přímé dítě), + (bezprostřední soused) a ~ (obecný sourozenec).

2. Atributové selektory

Zápisy [attr], [attr^=] (začíná), [attr$=] (končí) a [attr*=] (obsahuje).

3. Pseudotřídy :nth-child vs. :nth-of-type

:nth-child počítá všechny sourozence bez ohledu na tag, zatímco :nth-of-type filtruje pouze elementy stejného typu.

4. Pseudoelementy ::before a ::after

Vytváření virtuálního obsahu v Render Tree, nutnost zadat content a vliv na specificitu (započítávají se jako tagy).

Klasický chyták zkoušejícího

„V sekci máme nadpis <h2> a za ním odstavce <p>. Zacílí pravidlo p:first-child na první odstavec?“
Správná odpověď: Nezacílí! Protože prvním potomkem sekce je nadpis <h2>, podmínka „být odstavcem A ZÁROVEŇ být prvním potomkem“ není splněna. Pro zacílení na první odstavec se musí použít p:first-of-type nebo kombinátor h2 + p.
