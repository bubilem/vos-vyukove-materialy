Responzivní design (RWD) & Media Queries

Filozofie Mobile-First, konfigurace meta viewportu, tvorba fluidních rozvržení, breakpointy pomocí @media pravidel a moderní reaktivní stylování pomocí CSS proměnných.

Metodika návrhu Mobile-First, @media, Custom Properties
Referenční model Responzivní adaptace edu_portal

Základní principy

Tři pilíře responzivního webdesignu (Ethan Marcotte)

Jak vytvořit jeden web, který funguje optimálně na libovolném zařízení

Otázka u zkoušky

1. Meta Viewport

Instrukce pro mobilní prohlížeč, aby zobrazil web v poměru 1:1 k fyzickým CSS pixelům displeje a neoddaloval stránku na virtuálních 980 pixelů:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

2. Fluidní rozvržení (Mřížka)

Místo fixních šířek v pixelech (např. width: 960px) se používají poměrné jednotky (%, fr, vw, max-width), které se přizpůsobí šířce okna.

3. Flexibilní média

Obrázky a videa nesmí nikdy přetéct svůj rodičovský kontejner:

img, video { max-width: 100%; height: auto; }
Nikdy nezakazujte zoom uživateli!

Atribut user-scalable=no nebo maximum-scale=1.0 je hrubým porušením přístupnosti (WCAG). Zrakově hendikepovaný uživatel musí mít možnost si text na mobilu přiblížit gestem prstů.

Strategie kódování

Filozofie Mobile-First a pravidlo @media

Progresivní rozšiřování pomocí min-width vs. Desktop-First degradace

css • mobile-first architektura 
/* 1. VÝCHOZÍ STYLY: Mobilní telefon (1 sloupec) */
.container {
  display: flex;
  flex-direction: column;
  padding: 1rem;
}

/* 2. TABLET: Od šířky 768px a více */
@media screen and (min-width: 768px) {
  .container {
    flex-direction: row;
  }
}

/* 3. DESKTOP: Od šířky 1024px a více */
@media screen and (min-width: 1024px) {
  .container {
    max-width: 1200px;
    margin: 0 auto;
  }
}

Proč je Mobile-First průmyslovým standardem?

  • Progresivní rozšiřování: Začínáme s nejjednodušším čistým kódem bez zbytečných floatů a pozicování. Teprve pro větší obrazovky přidáváme sloupce.
  • Výkon na mobilních sítích: Mobilní telefon nemusí stahovat a přepisovat složitá desktopová pravidla s max-width.
  • SEO & Google Mobile-First Indexing: Vyhledávače hodnotí a indexují prioritně mobilní verzi stránky.
Moderní CSS

CSS Custom Properties: Nativní proměnné

Dynamická změna barevných témat (Dark/Light mode) za běhu aplikace

css • dark / light mode téma 
/* Globální proměnné v kořeni dokumentu */
:root {
  --bg-body: #0a0f1d;
  --text-body: #f3f4f6;
  --accent-color: #06b6d4;
}

/* Přepnutí do světlého režimu */
[data-theme="light"] {
  --bg-body: #f8fafc;
  --text-body: #0f172a;
}

body {
  background-color: var(--bg-body);
  color: var(--text-body);
  transition: background 0.3s ease;
}

Výhody nativních CSS proměnných

  • Žijí v DOM stromu: Na rozdíl od proměnných v Sassu nebo Lessu (které zanikají při kompilaci) nativní proměnné existují v prohlížeči v reálném čase.
  • Kaskádují a dědí se: Můžete předefinovat proměnnou --card-bg lokálně pouze pro určitou sekci .highlight-box.
  • Manipulace přes JavaScript: Lze číst a měnit jedním příkazem:
    element.style.setProperty('--accent', '#ff0000');
  • Reakce na systém: Snadná vazba na systémový dark mode: @media (prefers-color-scheme: dark).
Micro-interactions & Performance

Plynulé přechody (Transitions) a výkon

Animace akcelerované grafickou kartou (GPU) bez zasekávání stránky

css • plynulý hover efekt na kartě 
.course-card {
  background: rgba(255, 255, 255, 0.05);
  border: 1px solid var(--border-color);
  /* Zápis: vlastnost | trvání | funkce | zpoždění */
  transition: transform 0.25s cubic-bezier(0.16, 1, 0.3, 1), 
              box-shadow 0.25s ease;
}

.course-card:hover {
  /* Hardwarově akcelerovaný posun nahoru */
  transform: translateY(-6px);
  box-shadow: 0 12px 24px rgba(0, 0, 0, 0.3);
}

Pravidla plynulých animací (60 FPS)

  • Animujte pouze transform a opacity: Tyto dvě vlastnosti se počítají přímo na GPU v samostatné kompoziční vrstvě (Compositor Thread). Nevyvolávají Reflow ani Repaint!
  • Nikdy neanimujte width, height, top nebo left: Animace geometrických rozměrů nutí prohlížeč přepočítávat polohu všech okolních prvků na stránce, což vede k zásekům (jank).
  • Respektujte preferenci uživatele: Pomocí @media (prefers-reduced-motion: reduce) vypněte animace uživatelům trpícím kinetózou.

Shrnutí & Požadavky k absolutoriu

Co musíte bezpečně ovládat z okruhu č. 16 (RWD)

Okruh absolutoria č. 16, 8

1. Tři pilíře RWD

Meta tag viewport, fluidní proporční mřížka (% / fr / rem) a flexibilní média (max-width: 100%).

2. Přístup Mobile-First

Výchozí styl pro malý displej s postupným přidáváním sloupců přes @media (min-width: ...).

3. CSS Custom Properties

Definice --nazev a volání var(). Žijí v DOMu a umožňují Dark mode bez duplikace stylů.

4. 60 FPS přechody

Animace přes transform a opacity akcelerované GPU vs. zákaz animování šířek a výšek.

Typická záludná otázka zkoušejícího

„Co se stane na iPhonu, pokud na stránku napíšete Media Queries pro mobil, ale zapomenete do HTML vložit značku <meta name="viewport" ...>?“
Správná odpověď: Media Queries pro mobil vůbec nezaberou! Mobilní prohlížeč bude předpokládat, že web není responzivní, nastaví šířku virtuálního okna na 980px, aplikuje desktopová pravidla a celou stránku zmenší na miniaturní nečitelný náhled.
