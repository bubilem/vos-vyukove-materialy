Tři pilíře RWD (Ethan Marcotte) a záhada Meta Viewportu

Proč bez jediné řádky v HTML mobilní telefony zobrazují desktopový „bleší tisk“

Otázka u zkoušky č. 16

1. Meta Viewport (1:1 poměr)

Příkaz pro mobilní prohlížeč: nastav šířku plátna přesně podle displeje mobilu (1:1). Zabraňuje tomu, aby telefon web zmenšil do nečitelného mikroskopického náhledu (virtuální 980px desktop).

2. Fluidní mřížka (% / fr / rem)

Opuštění pevných pixelů (960px). Proporční jednotky (%, fr, max-width), které se plynule přelévají podle dostupného prostoru.

3. Flexibilní média

Obrázky, videa a tabulky nesmí nikdy přetéct svůj kontejner: img, video { max-width: 100%; height: auto; }.

Simulovat chování mobilního prohlížeče:
html • povinná konfigurace v <head> 
<!-- Správná deklarace pro mobilní zařízení -->
<meta name="viewport" content="width=device-width, initial-scale=1.0">

Filozofie Mobile-First a pravidlo @media

Proč začínat od nejmenšího displeje a moderní zápis rozsahu šířek (Range Queries)

Otázka u zkoušky č. 16

Odpověď: Proč začínat od mobilu (Mobile-First)?

  • Progresivní rozšiřování: Výchozí kód pro mobil je čistý a přímočarý (1 sloupec). Větší displeje pouze přidávají sloupce přes min-width, místo aby mobil musel složitě přepisovat a rušit desktopové styly.
  • Výkon a rychlost: Mobilní zařízení mají méně paměti a pomalejší síť – nemusí tak stahovat a přebíjet těžký desktopový kód.
  • Google Mobile-First Indexing: Vyhledávače dnes hodnotí a řadí weby prioritně podle jejich mobilní verze.

Odpověď: Co jsou moderní Range Queries (Level 4)?

  • Intuitivní matematický zápis: Místo krkolomného (min-width: 768px) and (max-width: 1199px) píšeme přirozenou nerovnost: @media (768px <= width < 1200px).
  • Konec chyb s 1px mezerou: Odpadá známé dilema hraničních hodnot (např. zda psát 767px nebo 767.98px).
  • Univerzální podpora: Tento standard W3C plně podporují všechny moderní prohlížeče (Chrome, Firefox, Safari, Edge).
Zvolit šířku okna zařízení:
css • mobile-first kaskáda 
/* 1. VÝCHOZÍ STAV: Mobil (1 sloupec, postranní panel je skrytý) */
.sidebar {
  display: none; /* na mobilu a tabletu šetříme místo */
}

.courses-grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: 0.75rem;
}

/* 2. TABLET: min-width 768px (2 sloupce karet) */
@media (min-width: 768px) {
  .courses-grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* 3. DESKTOP: od 1200px (zobrazíme sidebar a přidáme mu sloupec) */
@media (width >= 1200px) {
  .sidebar {
    display: block; /* na velkém monitoru panel odkryjeme */
  }

  .courses-grid {
    grid-template-columns: 180px 1fr 1fr;
  }
}

Responzivní navigace: Hamburger menu vs. Desktopová lišta

Přístupný přerod horizontální navigace v mobilní drawer s velkými dotykovými terči

Otestovat stav navigace:
css • responzivní navigační logika 
/* Výchozí mobil: Hamburger viditelný, drawer skrytý */
.nav-burger { display: block; }
.nav-links  { display: none; }
.nav-links.is-open { display: flex; flex-direction: column; }

/* Desktop breakpoint (od 768px): Burger skryjeme */
@media (min-width: 768px) {
  .nav-burger { display: none; }
  .nav-links  { display: flex; flex-direction: row; }
}

Responzivní obrázky: srcset, sizes a element <picture>

Proč pouhé max-width: 100% nestačí a jak ušetřit až 90 % mobilních dat

Otázka u zkoušky č. 16, 18
Zvolit techniku obrázků:
html • naivní vložení obrázku 
<!-- Naivní zápis: Na mobil se zbytečně stáhne obří 4K snímek -->
<img src="hero-huge-2400.jpg" alt="Školní kampus">
Naivní obrázek (2400 px)
Přenáší se zbytečně 2400 × 1600 px
Přeneseno: 850 KB (Plýtvání)
Výkonnostní dopad: Závažná chyba: Prohlížeč stáhne 850 KB dat na 375px displej. To zhoršuje metriku LCP (Largest Contentful Paint) a vyčerpává mobilní FUP.

Jak přesně číst a psát syntaxi srcset a sizes?

  • Deskriptor w v srcset: campus-400.webp 400w – udává skutečnou fyzickou šířku souboru na disku (400 px). Prohlížeči tím říkáme nabídku dostupných variant bez nutnosti je stahovat.
  • Podmínka v sizes: (max-width: 600px) 100vw, 800px – má strukturu (media condition) slot-width, fallback-width. Na mobilu do 600px zabere 100vw (celou šířku), na větším displeji přesně 800px.
  • Matematika výběru: Prohlížeč vynásobí šířku slotu hustotou pixelů displeje (např. 400 px × 2× DPR Retina = 800 px) a ze srcset sám vybere nejmenší soubor, který stačí!

Proč to prohlížeč potřebuje a kdy volit <picture>?

  • Pre-parser fáze: Prohlížeč začíná stahovat obrázky ještě před načtením a zpracováním CSS stylů. Bez sizes by nevěděl, jak velký obrázek v layoutu bude!
  • Resolution Switching (použijte <img srcset sizes>): Když jde o tentýž motiv, který pouze servírujeme v různé datové velikosti (mobil vs desktop).
  • Art Direction (použijte <picture>): Když pro mobil měníme výřez a kompozici (detail obličeje místo širokého celku) nebo nabízíme moderní formát (AVIF → WebP → JPG).
Moderní CSS Math • Plynulá změna bez zlomů

Fluidní rozvržení bez Media Queries: Funkce clamp()

Konec skákajících nadpisů a pevných breakpointů – plynulý růst písma podle šířky okna

Táhněte posuvníkem šířky viewportu: Šířka: 600 px font-size: 24.5 px

Responzivní portál edu_portal

Vzorec: clamp(1.25rem, 0.85rem + 1.8vw, 2.5rem)
css • fluidní velikost písma a mezer 
/* Zápis: clamp(MINIMÁLNÍ, IDEÁLNÍ (dynamická), MAXIMÁLNÍ) */
h1 {
  font-size: clamp(1.25rem, 0.85rem + 1.8vw, 2.5rem);
}

/* Fluidní mezery v layoutu bez jediného @media dotazu! */
.container {
  gap: clamp(0.75rem, 2vw, 2.5rem);
}

Jak fungují matematické funkce CSS3?

  • clamp(MIN, VAL, MAX): Omezí hodnotu mezi spodní a horní mantinel. Na mobilu neklesne pod 1.25rem (20px), na velkém 4K monitoru nepřeroste 2.5rem (40px).
  • Plynulost (Interpolace): Mezi 320 px a 1400 px písmo plynule přibývá po zlomcích pixelů podle jednotky vw bez jediného vizuálního záškubu.
  • Využití: Nejen pro typografii, ale i pro padding, margin, gap nebo šířky sloupců.

Media Queries vs. Container Queries (@container)

Proč se dotazovat na velikost rodičovského bloku namísto celého okna prohlížeče

Umístit komponentu do stránky (při stejném desktopovém okně 1440 px):
css • autonomní container query 
/* 1. Rodičovský kontejner definuje kontext měření */
.card-slot {
  container-type: inline-size;
  container-name: cardBox;
}

/* 2. Karta se přizpůsobí šířce svého rodiče, NE oknu! */
.course-card {
  display: flex;
  flex-direction: column; /* výchozí úzký */
}

@container cardBox (min-width: 420px) {
  .course-card {
    flex-direction: row; /* široký kontejner */
  }
}
Rodičovský slot: šířka 480 px (@container min-width: 420px splněno!)

Režim média: Displej (Screen): Bohatá grafika, tmavé téma, interaktivní akční tlačítka. Při přímém odeslání do tiskárny by došlo k obrovskému plýtvání černým tonerem a vytištění zbytečných tlačítek.

Proč je "antiresponzivita" u tiskovin nutností?

  • Fixní fyzický formát: Papír formátu A4 má pevný rozměr 210 × 297 mm. Jakákoliv fluidní pružnost (např. 100vw) nebo mobilní přeskládání do jednoho sloupce by tiskopis zničilo.
  • Tiskové jednotky: Na rozdíl od obrazovkových pixelů pracujeme s fyzickými rozměry: milimetry (mm), centimetry (cm) a tiskovými body (pt – 1 pt = 1/72 palce).
  • Serverové generování PDF: Moderní e-shopy a informační systémy generují faktury a smlouvy v PDF přímo z HTML šablon přes Headless Chrome / Puppeteer. Přesné tiskové styly jsou základem této praxe!

Klíčová pravidla CSS Paged Media & @media print

  • Skrytí rozhraní: nav, .btn, .cookie-banner { display: none !important; } – tiskne se pouze čistý obsah dokumentu.
  • Rozepsání odkazů: Na papír nelze kliknout. Syntaxe a[href^="http"]::after { content: " (" attr(href) ")"; } automaticky vytiskne cílovou webovou adresu za text odkazů.
  • Pravidlo @page: @page { size: A4 portrait; margin: 20mm; } nastavuje fyzické okraje stránky bez vlivu nastavení tiskárny uživatele.
  • break-inside: avoid: Zabraňuje rozdělení tabulky, položky či razítka napůl přes spodní hranu stránky!

Slovník pojmů: Responzivní webdesign

Viewport (Virtuální vs. Vizuální)

Prohlížené okno dokumentu. Bez značky <meta name="viewport"> mobilní prohlížeče simulují desktop o šířce 980 px a web neúměrně zmenší. Nastavení width=device-width synchronizuje logické CSS pixely s displejem.

Mobile-First metodika

Strategie kódování, kdy výchozí CSS styly píšeme pro mobilní telefon (1 sloupec, nejmenší datová zátěž) a pro větší obrazovky pouze progresivně přidáváme pravidla pomocí @media (min-width: ...).

Breakpoint (Bod zlomu)

Konkrétní šířka viewportu v pixelech, při které dochází k přeskládání layoutu (např. 768 px pro tablet, 1200 px pro desktop). Moderní RWD doporučuje volit breakpointy podle obsahu, ne podle modelů telefonů.

Device Pixel Ratio (DPR)

Poměr mezi fyzickými hardwarovými pixely displeje a logickými CSS pixely. U displejů Retina/OLED je běžně DPR 2x až 3x, což vyžaduje obrázky ve vyšším rozlišení pro zachování ostrosti.

Fluidní typografie & clamp()

Matematická funkce clamp(min, val, max), která plynule mění velikost písma či mezer na základě dynamické jednotky vw, aniž by docházelo ke skokovým trhnutím layoutu.

Resolution Switching (srcset & sizes)

Atributy značky <img> umožňující nabídnout prohlížeči více variant stejného obrázku v různých rozlišeních, ze kterých prohlížeč sám vybere nejvhodnější soubor podle šířky a DPR displeje.

Art Direction (<picture>)

Technika, kdy pro různé obrazovky servírujeme záměrně odlišně oříznutý obrázek (např. detail obličeje na mobil a širokoúhlou scénu na desktop) pomocí značky <picture> a <source media="...">.

Container Queries (@container)

Pravidlo CSS umožňující stylovat komponentu podle šířky jejího bezprostředního rodičovského kontejneru (inline-size), čímž vytváří skutečně znovupoužitelné komponenty nezávislé na okně prohlížeče.

prefers-reduced-motion

Media query dotazující se na preferenci operačního systému uživatele. Umožňuje vypnout animace pro hendikepované uživatele trpící vestibulárními poruchami.

Tiskové styly (@media print)

Cílené CSS styly uplatněné při odeslání dokumentu do tiskárny nebo exportu do PDF. Slouží k odstranění rušivých prvků (navigace, bannery, tlačítka), úspoře toneru (černobílý tisk) a rozepsání hypertextových odkazů na fyzický papír.

CSS Paged Media & @page

Specifikace CSS pro stránkovaná média. Umožňuje definovat fyzické rozměry listu (např. @page { size: A4 portrait; margin: 20mm; }), řídit záhlaví a zápatí a zamezit nevhodnému roztržení bloků mezi stránky pomocí break-inside: avoid.
