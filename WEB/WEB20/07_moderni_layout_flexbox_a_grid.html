Moderní tvorba layoutu: Flexbox & CSS Grid

Od nepoddajného plovoucího layoutu (float) k nativním standardům CSS3: jednorozměrná pružná rozvržení (Flexbox) a dvourozměrný mřížkový systém (CSS Grid) pro portál edu_portal.

Systémy rozvržení Flexbox (1D) & Grid (2D)
Referenční model Navigace a magazín edu_portal
Zkouška / Absolutorium Okruh č. 11 (Tvorba layoutu v CSS)
Historie a motivace

Proč opustit Float a tabulky?

Vlastnost float byla navržena pro obtékání obrázků textem, nikoli pro celostránkový layout

Otázka u zkoušky

1. Éra tabulek (90. léta)

Zneužití <table> pro rozvržení. Nulová sémantika, obrovský kód, nemožnost responzivity pro mobilní telefony.

2. Éra floatu (2000–2012)

Použití float: left s nutností neustálého čištění obtékání (tzv. clearfix hack). Sloupce neměly stejnou výšku a vertikální centrování bylo noční můrou.

3. Moderní standardy (Dnes)

Nativní systémy navržené přímo pro layout: Flexbox (pro jednorozměrné toky) a CSS Grid (pro plnohodnotné 2D mřížky).

Základní pravidlo pro volbu systému

Flexbox řeší rozložení prvků v jednom směru (buď v řádku, NEBO ve sloupci). CSS Grid řídí rozvržení v obou směrech současně (sloupce A řádky naráz).

Jednorozměrné rozvržení (1D)

Flexbox: Hlavní osa, příčná osa a pružnost

Vlastnosti kontejneru vs. vlastnosti položek (items)

Vlastnosti flex kontejneru (display: flex)

  • flex-direction: row | column: Určuje směr hlavní osy (Main Axis).
  • justify-content: Zarovnání na hlavní ose (flex-start, center, space-between, space-around).
  • align-items: Zarovnání na příčné ose (stretch, center, flex-start).
  • gap: 1rem: Moderní elegantní definice mezer mezi položkami bez nutnosti marginů!
  • flex-wrap: wrap: Povolí zalomení položek na další řádek.

Vlastnosti položek (Flex Items)

  • flex-grow: 1: Schopnost prvku roztáhnout se a pohltit volné místo v kontejneru.
  • flex-shrink: 1: Míra smrštění, pokud kontejner nestačí.
  • flex-basis: 200px: Výchozí velikost před rozdělením volného místa.
  • flex: 1 1 auto (nebo zkráceně flex: 1): Zkratka pro grow, shrink a basis.
  • align-self: center: Individuální přebití align-items pro jednu položku.
Dvourozměrná mřížka (2D)

CSS Grid: Mřížkový systém nové generace

Frakční jednotka fr, funkce repeat(), minmax() a automatické zalamování

css • responzivní mřížka karet 
.course-grid {
  display: grid;
  /* Automaticky vytvoří tolik sloupců, kolik se vejde,
     každý minimálně 280px, jinak se pružně roztáhnou (1fr) */
  grid-template-columns: repeat(
    auto-fit, 
    minmax(280px, 1fr)
  );
  gap: 1.5rem;
}

Klíčové prvky CSS Gridu

  • Frakční jednotka (fr): Reprezentuje poměrný podíl na volném prostoru mřížky (např. 1fr 2fr 1fr rozdělí šířku na 4 díly).
  • minmax(min, max): Nastavuje spodní a horní hranici velikosti buňky.
  • auto-fit vs. auto-fill: Umožňuje vytvořit plně responzivní layout zcela bez media queries!
  • Umísťování: grid-column: 1 / 3 roztáhne položku přes první dva sloupce.
Komplexní layout

Pojmenované oblasti: grid-template-areas

Vizuální ASCII-art mapa celého portálu v CSS kódu

css • layout portálu edu_portal 
.portal-layout {
  display: grid;
  grid-template-columns: 260px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  min-height: 100vh;
  gap: 1rem;
}

.site-header  { grid-area: header; }
.site-sidebar { grid-area: sidebar; }
.site-main    { grid-area: main; }
.site-footer  { grid-area: footer; }

Výhody grid-template-areas

  • Čitelnost kódu: Na první pohled vidíte celkové uspořádání stránky přímo v CSS.
  • Okamžitá responzivita: V media query pro mobilní telefon stačí pouze přepsat matici do jednoho sloupce:
    grid-template-areas:
      "header"
      "main"
      "sidebar"
      "footer";
  • Nezávislost na pořadí v HTML: Pozici bloku změníte bez jediného zásahu do HTML značkování.

Okruh absolutoria č. 11

1. Kdy Flexbox

Pro jednorozměrná rozvržení (1D), navigační lišty, tlačítkové skupiny, vertikální vycentrování.

2. Kdy CSS Grid

Pro dvourozměrná rozvržení (2D), komplexní kostru stránky, fotogalerie, katalogy karet.

3. Frakční jednotka fr

Zlomkový podíl na volném místě. Zabraňuje zaokrouhlovacím chybám v procentech.

4. Responzivní auto-fit

Kombinace repeat(auto-fit, minmax(250px, 1fr)) zajistí responzivní sloupce bez media queries.

Typická otázka zkoušejícího

„Jaký je přesný rozdíl mezi justify-content a align-items ve Flexboxu?“
Správná odpověď: justify-content zarovnává položky podél hlavní osy (Main Axis), která je definována vlastností flex-direction (ve výchozím stavu vodorovně). align-items zarovnává položky podél příčné osy (Cross Axis), která je na hlavní osu kolmá (ve výchozím stavu svisle).
