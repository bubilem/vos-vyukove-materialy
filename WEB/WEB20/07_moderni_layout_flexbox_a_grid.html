Evoluce layoutu: Proč opustit Float a jak volit systém?

Vlastnost float byla navržena pro obtékání obrázků textem v novinách, nikoli pro celostránkovou mřížku

Otázka u zkoušky č. 11

1. Éra tabulek (90. léta)

Zneužití <table> pro vizuální rozvržení webu. Fatální dopad na sémantiku, nepřístupné pro čtečky obrazovky a absolutní nemožnost responzivity pro displeje telefonů.

2. Éra floatu & hacků (2000–2012)

Rozmísťování pomocí float: left a inline-block. Nutnost tzv. clearfix hacků kvůli kolapsu výšky rodiče, sloupce neměly stejnou výšku a vertikální vycentrování vyžadovalo krkolomné triky.

3. Moderní standardy (Dnes)

Nativní W3C systémy navržené přímo pro layout: Flexbox (pro jednorozměrné toky komponent) a CSS Grid (pro robustní dvourozměrnou mřížku celé stránky i složitých komponent).

Porovnat přístup v praxi:
css • flexbox (content-out) 
/* Flexbox: Položky si řídí šířku podle délky svého obsahu */
.container {
  display: flex;
  gap: 1rem;
}

Podstatně delší obsah textu
Střední prvek
Princip: Content-Out (Flexbox): Každý box si vzal šířku přesně podle svého textu. Prvky jsou volně seřazené v jednom směru.
Jednorozměrné rozvržení (1D) • Pružnost a osy

Flexbox: flex-grow, flex-shrink, basis a kouzlo margin: auto

Vysvětlení výpočtu volného místa, chování zkratek flex a přišpendlení prvků v navigaci

Hlavní osa (Main Axis) → flex-direction: row | column Příčná osa (Cross Axis) → vždy kolmá na hlavní osu
Zvolit scénář pružnosti:
css • rovnoměrné dělení flex: 1 
/* Všechny položky ignorují původní šířku a dělí se přesně rovným dílem */
.container {
  display: flex;
  gap: 0.75rem;
}

.item {
  flex: 1; /* Zkratka za flex: 1 1 0% */
}

Box 02 33.3 % šířky

Vysvětlení: flex: 1 nastavuje flex-basis: 0% → veškerá šířka kontejneru je považována za volné místo a je rozdělena naprosto rovnoměrně bez ohledu na obsah!

Dvourozměrná mřížka (2D) • CSS Grid

CSS Grid: Mřížkový systém, jednotka fr a automatický layout

Rozdíl auto-fit vs. auto-fill, algoritmus grid-auto-flow: dense a implicitní mřížka

Zvolit automatický scénář:
css • auto-fit responzivita 
/* auto-fit: Vytvoří tolik sloupců, kolik se vejde,
   a existující sloupce roztáhne (1fr) na 100 % šířky */
.grid-container {
  display: grid;
  grid-template-columns: repeat(
    auto-fit, 
    minmax(120px, 1fr)
  );
  gap: 0.65rem;
}

Karta 3
Vysvětlení chování: auto-fit: I když máme jen 3 karty na širokém kontejneru, sloupce se díky 1fr roztáhnou přes celou dostupnou šířku bez zbytečného prázdného místa.

Pokročilé vzory • Reálné rozvržení

Pokročilý Grid: Pojmenované oblasti a revoluce CSS Subgrid

Vizuální ASCII mapa portálu edu_portal a řešení rozházených tlačítek ve vnořených kartách

Zvolit pokročilou techniku:
css • desktop rozvržení edu_portal 
.portal-layout {
  display: grid;
  grid-template-columns: 160px 1fr;
  grid-template-areas:
    "header  header"
    "sidebar main"
    "footer  footer";
  gap: 0.65rem;
}

.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }
.footer  { grid-area: footer; }
Technické shrnutí: grid-template-areas vytváří přehlednou ASCII-art mapu celé stránky přímo v CSS.

Shrnutí & Požadavky k absolutoriu

Srovnávací matice Flexbox vs. CSS Grid a co musíte bezpečně ovládat u zkoušky

Okruh absolutoria č. 11
Vlastnost / Kritérium Flexbox (CSS Flexible Box) CSS Grid (Two-Dimensional Grid)
Dimenze rozvržení Jednorozměrná (1D): pouze řádek, NEBO sloupec Dvourozměrná (2D): řádky I sloupce současně
Architektonická filozofie Content-Out: položky si řídí šířku podle obsahu Container-In: kontejner pevně diktuje geometrii mřížky
Centrování položek justify-content: center; align-items: center; place-items: center; (vše na 1 řádek)
Automatický layout flex-wrap: wrap; flex: 1 1 200px; repeat(auto-fit, minmax(250px, 1fr));
Typické nasazení Navigační lišty, tlačítka, formulářová pole, vnitřek karet Kostra stránky (Holy Grail), katalogy karet, dashboardy, fotogalerie

1. justify-* vs. align-*

justify-* působí podél hlavní / inline osy. align-* působí podél příčné / blokové osy.

2. auto-fit vs. auto-fill

auto-fit roztáhne existující sloupce na celou šířku. auto-fill zachová volné prázdné stopy.

3. flex: 1 vs. flex: auto

flex: 1 má basis: 0% (rovnoměrný podíl). flex: auto má basis: auto (počítá velikost obsahu).

4. Kdy co nasadit

Grid na kostru webu a 2D mřížky karet. Flexbox na jednorozměrné toky a zarovnání prvků uvnitř komponent.

Doporučení pro zkouškovou obhajobu

Při obhajobě maturitního či absolventského projektu vždy ukažte, že nepoužíváte zastaralé floaty ani desítky media queries. Vyzdvihněte resilientní layouty s auto-fit, čistou navigaci s margin-left: auto a sémantickou mapu stránek pomocí grid-template-areas. Stisknutím klávesy G otevřete odborný slovník pojmů.

Slovník pojmů: Flexbox & CSS Grid

Main Axis (Hlavní osa)

Osa, podél které se primárně řadí pružné položky ve Flexboxu. Její směr určuje flex-direction (ve výchozím stavu row, tedy zleva doprava).

Cross Axis (Příčná osa)

Osa kolmá na hlavní osu. Pro flex-direction: row vede svisle shora dolů. Zarovnání podél ní řídí align-items a align-self.

Flex Basis

Počáteční velikost prvku předtím, než flexbox algoritmus začne rozdělovat zbývající volné místo nebo položky smršťovat.

Grid Track (Mřížková stopa)

Prostor mezi dvěma sousedními mřížkovými linkami – tedy buď jeden sloupec, nebo jeden řádek.

Frakční jednotka (fr)

Flexibilní jednotka v CSS Gridu reprezentující zlomkový podíl na volném prostoru mřížky po odečtení pevných hodnot a mezer (gap).

Implicitní mřížka (Implicit Grid)

Stopy, které vytvoří prohlížeč automaticky, pokud obsah přeteče definovanou šablonu (explicitní grid). Jejich rozměr řídí grid-auto-rows a grid-auto-columns.

Auto-placement (dense)

Algoritmus automatického umísťování v gridu s hodnotou dense, který zpětně zaplňuje prázdná místa zanechaná velkými položkami.

CSS Subgrid

Vlastnost umožňující vnořenému prvku zdědit a sdílet řádkové či sloupcové stopy svého rodičovského gridu, čímž zajišťuje dokonalou návaznost linií.
