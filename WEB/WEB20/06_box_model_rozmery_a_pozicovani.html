1. Content (Obsah) width • height

Jádro krabičky, kde se vykresluje text, obrázky nebo vnoření potomci. Rozměry jsou řízeny vlastnostmi width a height (v ukázce 300 × 120 px).

2. Padding (Vnitřní výplň) padding: 25px

Vnitřní odstup mezi obsahem a rámečkem. Přebírá pozadí prvku (background-color i obrázek) a je aktivní součástí klikací plochy odkazů a tlačítek!

3. Border (Rámeček) border: 5px solid

Ohraničení krabičky obklopující padding. Má nastavitelnou tloušťku, styl (solid, dashed, ...) i barvu. Tvoří vnější mez pro ořez pozadí (background-clip).

4. Margin (Vnější okraj) margin: 20px

Vnější odstup od okolních sousedních prvků. Je zcela průhledný (nepřebírá barvu pozadí prvku) a ve svislém směru podléhá pravidlu kolapsu.

Zkouškový chyták: Kolaps vertikálních vnějších okrajů (Margin Collapsing)

Svislé vnější okraje (margin-top a margin-bottom) sousedních bloků se nesčítají! Sloučí se do jediného okraje rovnajícího se větší z obou hodnot (např. margin-bottom: 30px a následující margin-top: 20px vytvoří mezeru 30 px, nikoli 50 px!). Vodorovné okraje (left/right) nekolabují nikdy.

css • globální reset box-sizing (povinný základ) 
/* Zlaté pravidlo moderního CSS – vložit na začátek každého projektu: */
*, *::before, *::after {
  box-sizing: border-box;
}
Živý test: 2 sloupce (width: 50%) v layoutu
Sloupec A width: 50%
Sloupec B width: 50%
Chyba: Sloupce se nafoukly o padding a rámeček (50% + 24px) → přetekly 100% šířku a zalomily se pod sebe!
Perfektní: Padding i rámeček jsou uvnitř 50% šířky → oba sloupce drží přesně vedle sebe!
Délkové jednotky • Tisk & Procenta

Absolutní jednotky, tiskové standardy & Procenta (%)

Fyzické jednotky pro tisk (cm, mm, in, pt), referenční px a pravidla výpočtu procent v CSS

Otázka u zkoušky č. 10

Fyzické & Tiskové jednotky (@media print)

Mají pevný přepočet na reálný svět. Zásadní význam mají při přípravě tiskových stylů webu (faktury, smlouvy, jízdenky):

cm mm
Centimetry a milimetry: Fyzické jednotky pro tiskové šablony formátu A4 (210 × 297 mm), okraje stránek, štítky či průkazky.
pt
Body (Points): Tradiční DTP jednotka (1pt = 1/72 palce ≈ 0.353 mm). Standard pro velikost písma v tisku (běžný text má 10pt–12pt).
in pc
Palce (Inches) a Picas: 1in = 2.54cm = 72pt = 96px. 1pc (pica) = 12pt.
px
CSS Pixel: Referenční pixel obrazovek (1px = 1/96 in). Fixní pro displeje, vhodný pro rámečky (1px solid) a stíny, nevhodný pro responzivní text.
css • tisková sestava faktury 
@media print {
  @page { size: A4 portrait; margin: 2cm 1.5cm; }
  body { font-size: 11pt; color: #000; }
  .faktura-table { width: 100%; border: 0.5mm solid #000; }
}

Procentuální jednotka (%) a kontextuální výpočet

Procenta jsou vždy poměrná hodnota vypočítaná z nadřazeného kontextu. Pozor na odlišné chování dle vlastnosti:

width: %
Počítá se z šířky (width) bezprostředního rodiče. Základ vícesloupcových mřížek a adaptivních layoutů.
height: %
Častá past: Funguje pouze tehdy, má-li rodič explicitně zadanou výšku (px, vh). Má-li rodič height: auto, procenta potomka se ignorují!
padding: %
Záludnost u zkoušky: Svislý i vodorovný padding i margin v % se v CSS počítají ze ŠÍŘKY (width) rodiče (kvůli udržení poměru stran)!
font-size: %
Relativní vůči font-size rodiče (např. 125% = 1.25× větší než písmo rodiče).
translate(%)
Počítá se z rozměru samotného elementu (nikoli rodiče!). Klíč k dokonalému absolutnímu centrování.
Trik pro absolutní centrování (Rodič vs. Element)

top: 50%; left: 50%; posune počátek prvku do středu rodiče.
transform: translate(-50%, -50%); vrátí prvek zpět o 50 % své vlastní šířky a výšky!

Responzivní geometrie & Matematika

Relativní jednotky (rem, em, ch), Viewport & fluidní výpočty

Typografie přístupná pro slabozraké, mobilní jednotky (dvh, svh) a moderní funkce clamp() a calc()

Okruh č. 10

rem (Root EM)

1rem = 16px

Relativní vůči velikosti písma kořene <html>. Zlatý standard přístupnosti (a11y): Pokud si slabozraký uživatel zvětší výchozí písmo v systému, celý web v rem se plynule zvětší s ním!

em (Element EM)

Rodičovské

Relativní vůči písmu aktuálního elementu nebo rodiče. Ideální pro škálovatelná tlačítka a ikony (padding: 0.5em 1.2em roste spolu s textem tlačítka). Pozor na lavinové násobení v seznamech.

ch (Character zero)

Šířka '0'

Přesná šířka číslice 0 v aktuálním fontu. Typografické pravidlo čitelnosti: Odstavec textu by měl mít 50–75 znaků na řádek pro pohodlné čtení → max-width: 65ch;.

Jednotky Viewportu (vw, vh, dvh, svh)

Rozměry počítané z viditelného okna prohlížeče:

vw / vh
1vw = 1 % šířky okna, 1vh = 1 % výšky okna. vmin / vmax = minimum/maximum z obou.
dvh / svh
Mobilní revoluce: Na mobilech (iOS Safari, Android Chrome) klasické 100vh přetéká pod systémovou lištu!
• svh = výška při vysunuté liště (Small).
• dvh (Dynamic Viewport Height): dynamicky reaguje na stav lišty!

Funkce calc(), clamp(MIN, VAL, MAX) & min()

css • fluidní typografie & layout 
/* Kombinace nekompatibilních jednotek: */
.sidebar { width: calc(100% - 250px); }
.hero    { min-height: calc(100dvh - 64px); }

/* Fluidní nadpis: min 1.8rem, roste s oknem (4vw), max 3.5rem: */
h1 { font-size: clamp(1.8rem, 4vw + 1rem, 3.5rem); }
Řízení polohy

CSS Pozicování: static, relative, absolute, fixed, sticky

Vyjmutí z normálního toku dokumentu a kontext vrstev z-index

Okruh č. 11
Hodnota V toku dokumentu? Chování a referenční bod (top/left)
static ANO Výchozí stav. Vlastnosti top, left, z-index nemají žádný efekt.
relative ANO Posouvá se vůči své původní pozici. Původní místo v toku zůstává rezervováno. Vytváří kontext pro potomky s absolute.
absolute NE Vyjmut z toku. Pozicuje se vůči nejbližšímu předkovi, který má pozici jinou než static.
fixed NE Vyjmut z toku. Pozicuje se přímo vůči oknu prohlížeče (viewportu). Při skrolování zůstává na stejném místě.
sticky Hybridní Chová se jako relative, dokud nedosáhne zadané hranice (např. top: 0), pak se „přilepí“ jako fixed uvnitř svého rodiče.
Jak funguje vrstvení z-index?

Vlastnost z-index funguje POUZE na pozicované elementy (position různá od static). Pozor: Potomek vnořený v rodiči s nižším kontextem vrstvení (Stacking Context) nemůže nikdy přesáhnout prvek s vyšším z-indexem na vyšší úrovni stromu!

Zkouškový checklist & Syntéza

Shrnutí & Požadavky k absolutoriu

Co musíte bezpečně ovládat z okruhů č. 10 a č. 11

Okruh absolutoria č. 10, 11

1. Box Model vrstvy

Content → Padding → Border → Margin. Svislý margin kolabuje (spojuje se do maxima obou hodnot).

2. box-sizing: border-box

Padding a border se zařezávají dovnitř zadané šířky. Klíčový předpoklad nerozbitného moderního layoutu.

3. Velikostní jednotky

Tisk: cm, mm, pt; Přístupnost: rem; Komponenty: em; Text: ch; Kontext: %; Mobil: dvh.

4. Režimy pozicování

relative (tvoří kontext), absolute (hledá pozicovaného rodiče), fixed (viewport), sticky (přilepení).

Typická záludná otázka u zkoušky

„Vložíme prvek s position: absolute; top: 10px; right: 10px;. Kam přesně se umístí, pokud žádný z jeho rodičů nemá nastavenou vlastnost position?“
Správná odpověď: Umístí se 10px od pravého horního rohu počátečního bloku dokumentu (Initial Containing Block), tedy prakticky vůči celému oknu/stránce <html>, nikoliv vůči svému přímému HTML rodiči!
