Anatomie CSS Box Modelu

Čtyři koncentrické obdélníky každého HTML elementu v toku dokumentu

Otázka u zkoušky

1. Content (Obsah)

Jádro krabičky, kde je vykreslen text, obrázek nebo potomkové elementy. Rozměry jsou řízeny vlastnostmi width a height.

2. Padding (Výplň)

Vnitřní odsazení mezi obsahem a rámečkem. Má barvu pozadí elementu (background-color) a je klikatelnou součástí prvku.

3. Border (Rámeček)

Ohraničení krabičky obklopující padding. Může mít různou tloušťku, styl (solid, dashed) i barvu.

4. Margin (Vnější okraj)

Odstup od okolních elementů. Je zcela průhledný a nespadá pod pozadí elementu.

Kolaps vertikálních vnějších okrajů (Margin Collapsing)

Svislé okraje dvou sousedních blokových elementů se nesčítají! Místo toho se „zhroutí“ (sloučí) a výsledná mezera se rovná pouze maximálnímu z obou okrajů (např. margin-bottom: 30px a margin-top: 20px vytvoří mezeru pouze 30px, nikoli 50px).

Řízení výpočtu rozměrů

Revoluce box-sizing: content-box vs. border-box

Proč se historicky webové layouty rozpadaly po přidání paddingu

content-box (Historický standard W3C)

Nastavená width určuje pouze šířku obsahu. Přidáním paddingu a borderu se celková šířka prvku na obrazovce nafoukne:

Zadáno: width: 300px; padding: 20px; border: 5px;
Výsledná šířka na obrazovce: 350 px (300 + 40 + 10)

Výsledek: Dva 50% bloky vedle sebe přetečou řádek a spadnou pod sebe!

border-box (Moderní standard praxe)

Nastavená width je konečná celková šířka prvku. Padding i rámeček se zařezávají směrem dovnitř:

Zadáno: width: 300px; padding: 20px; border: 5px;
Výsledná šířka na obrazovce: přesně 300 px

Výsledek: Dva 50% bloky zůstanou vždy přesně vedle sebe.

css • globální reset box-sizing 
/* Zlaté pravidlo moderního CSS – aplikovat na každý webový projekt: */
*, *::before, *::after {
  box-sizing: border-box;
}
Délkové jednotky

Absolutní vs. Relativní jednotky & clamp()

Proč v moderním responzivním vývoji vítězí rem nad pixely

px (Pixely)

Absolutní fixní jednotka. Nerespektuje uživatelské nastavení velikosti písma v prohlížeči. Vhodné pouze pro jemné linky rámečků (1px solid) nebo box-shadow.

rem (Root EM)

Relativní vůči kořenovému elementu <html> (typicky výchozí 1rem = 16px). Pokud si slabozraký uživatel zvětší písmo v systému, web se plynule zvětší s ním!

em vs. rem

em se vztahuje k písmu aktuálního rodiče (může se lavinovitě násobit!). rem je stabilní, protože se vztahuje vždy ke kořeni <html>.

Moderní fluidní typografie pomocí funkce clamp(MIN, VAL, MAX)

css • fluidní velikost nadpisu 
h1.hero-title {
  /* Nikdy méně než 1.8rem na mobilu, plynule roste s oknem (4vw), max 3.5rem na velkém monitoru */
  font-size: clamp(1.8rem, 4vw + 1rem, 3.5rem);
}
Řízení polohy

CSS Pozicování: static, relative, absolute, fixed, sticky

Vyjmutí z normálního toku dokumentu a kontext vrstev z-index

Hodnota V toku dokumentu? Chování a referenční bod (top/left)
static ANO Výchozí stav. Vlastnosti top, left, z-index nemají žádný efekt.
relative ANO Posouvá se vůči své původní pozici. Původní místo v toku zůstává rezervováno. Vytváří kontext pro potomky s absolute.
absolute NE Vyjmut z toku. Pozicuje se vůči nejbližšímu předkovi, který má pozici jinou než static.
fixed NE Vyjmut z toku. Pozicuje se přímo vůči oknu prohlížeče (viewportu). Při skrolování zůstává na stejném místě.
sticky Hybridní Chová se jako relative, dokud nedosáhne zadané hranice (např. top: 0), pak se „přilepí“ jako fixed uvnitř svého rodiče.
Jak funguje vrstvení z-index?

Vlastnost z-index funguje POUZE na pozicované elementy (position různá od static). Pozor: Potomek vnořený v rodiči s nižším kontextem vrstvení (Stacking Context) nemůže nikdy přesáhnout prvek s vyšším z-indexem na vyšší úrovni stromu!

Okruh absolutoria č. 10, 11

1. Box Model vrstvy

Content → Padding → Border → Margin. Svislý margin kolabuje (spojuje se do maxima).

2. box-sizing: border-box

Padding a border se započítávají do celkové zadané šířky. Klíčový předpoklad moderního layoutu.

3. rem vs. em vs. px

Pixely jsou fixní, rem je přístupný a škáluje podle kořenového nastavení, em se váže na rodiče.

4. Režimy pozicování

relative (tvoří kontext), absolute (hledá pozicovaného rodiče), fixed (viewport), sticky (přilepení).

Typická záludná otázka u zkoušky

„Vložíme prvek s position: absolute; top: 10px; right: 10px;. Kam přesně se umístí, pokud žádný z jeho rodičů nemá nastavenou vlastnost position?“
Správná odpověď: Umístí se 10px od pravého horního rohu počátečního bloku dokumentu (Initial Containing Block), tedy prakticky vůči celému oknu/stránce <html>, nikoliv vůči svému přímému HTML rodiči!
