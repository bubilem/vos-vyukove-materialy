Způsoby začlenění stylů a syntaxe pravidla

Srovnání externího souboru, interního bloku a inline stylu

Otázka u zkoušky

1. Externí stylopis (Doporučeno)

<link rel="stylesheet" href="style.css">

Úplné oddělení obsahu a vzhledu, možnost cachování v prohlížeči pro celý portál, snadná údržba.

2. Interní blok <style>

<style> body { margin: 0; } </style>

Vhodné pouze pro specifické styly jediné stránky nebo pro rychlé vložení Critical CSS do hlavičky.

3. Inline atribut style

<div style="color: red;">...</div>

Antipattern! Míchá data s prezentací, nelze cachovat, má extrémní specificitu a nelze v něm psát media queries.

css • anatomie pravidla 
.site-header .nav-link {
  color: #06b6d4;         /* Deklarace: vlastnost: hodnota; */
  font-size: 1rem;
  text-decoration: none;
}
Jádro kaskádových stylů

Princip kaskády (The Cascade)

Jak prohlížeč řeší kolize protichůdných deklarací pro jeden element

Když na stejný element cílí více pravidel definujících tutéž vlastnost (např. color), prohlížeč vyhodnocuje pravidla podle kaskádového algoritmu v tomto pořadí:

1. Důležitost & Původ

Pravidla s !important > autorský styl webu > uživatelský styl > výchozí styl prohlížeče (User Agent).

2. Inline styl

Pravidlo zapsané přímo v HTML atributu style="..." přebíjí všechny selektory z externích CSS.

3. Specificita (Váha)

Čím přesnější a specifičtější je selektor, tím vyšší váhu má. Pravidlo s vyšší specificitou zvítězí.

4. Pořadí ve zdroji

Pokud mají dvě deklarace stejnou specificitu, vítězí ta, která je v CSS souboru níže (později).

Matematický model

Výpočet specificity selektorů: Vzorec (A, B, C, D)

Objektivní hodnocení váhy selektoru bez dohadů

Požadavek absolutoria
Složka Co započítává Příklady
A (1,0,0,0) Inline styl style="color: red;"
B (0,1,0,0) Identifikátory (ID) #main-nav, #header
C (0,0,1,0) Třídy, atributové selektory, pseudotřídy .btn, [type="text"], :hover
D (0,0,0,1) Typové prvky (tagy) a pseudoelementy p, h1, div, ::before

Tréninkové příklady specificity:

  • nav a → (0, 0, 0, 2)
  • .nav-item .active → (0, 0, 2, 0) (vyšší než tagy!)
  • #sidebar .widget h3 → (0, 1, 1, 1)
  • #nav a:hover → (0, 1, 1, 1)
Proč nepoužívat !important?

Klíčové slovo !important rozbíjí přirozenou kaskádu. Jediný způsob, jak jej přebít, je napsat další !important s vyšší specificitou. To vede k nekontrolovatelné „válce specificit“.

Základní chování

Dědičnost vlastností & CSS Reset vs. Normalize

Jak se styly šíří od rodičů a jak sjednotit výchozí zobrazení v prohlížečích

Děděné vs. Neděděné vlastnosti

  • Děděné (Inherited): Typografie a text (color, font-family, font-size, line-height, text-align). Nastavíte-li font na <body>, zdědí jej všechny odstavce i nadpisy.
  • Neděděné: Geometrie krabičky (margin, padding, border, width, background). Kdyby se dědil rámeček, každý odstavec by orámoval i všechny své potomky.
  • Klíčová slova: inherit (vynutí dědění), initial (výchozí stav z W3C specifikace), unset.

CSS Reset vs. Normalize.css

  • CSS Reset (Eric Meyer): Agresivně vynuluje veškeré okraje, paddingy a velikosti písem u všech tagů (všechny tagy začínají na čisté nule).
  • Normalize.css (Moderní standard): Zachovává užitečné výchozí styly prohlížečů, ale odstraňuje mezi-prohlížečové nekonzistence a opravuje běžné bugy.
  • Moderní CSS Reset (Dnes): Zaměřuje se na box-sizing: border-box;, odstranění výchozího marginu na body a plynulý rendering obrázků.

Co musíte bezpečně ovládat z okruhu č. 8 (CSS kaskáda a specificita)

Okruh absolutoria č. 8

1. Kaskáda a pořadí

Řešení konfliktů: Původ stylu → Inline → Specificita → Pořadí v souboru (poslední vyhrává).

2. Vzorec specificity

Čtyři hodnoty (Inline, ID, Třídy/Pseudotřídy, Tagy/Pseudoelementy). Deset tříd nikdy nepřeváží jedno ID.

3. Dědičnost vlastností

Textové vlastnosti se dědí automaticky, box modelové se nedědí. Možnost vynucení přes inherit.

4. Sjednocení stylů

Význam Normalize.css pro konzistentní renderování napříč různými prohlížeči a platformami.

Typická výpočetní úloha u zkoušky

„Které pravidlo obarví odkaz na stránce: #main-menu a { color: blue; } nebo header.site-header nav.main-navigation ul.menu-list li.menu-item a.link { color: red; }?“
Správná odpověď: Odkaz bude modrý! První pravidlo obsahuje jedno ID → specificita (0, 1, 0, 1). Druhé pravidlo má sice 4 třídy a 4 tagy, ale 0 ID → specificita (0, 0, 4, 4). ID má v kaskádě vyšší řádovou váhu.
