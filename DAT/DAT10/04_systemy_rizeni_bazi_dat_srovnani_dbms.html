Zkouška / Absolutorium Okruh č. 2
Typologie systémů

Kategorie SŘBD: Serverové vs. Vestavěné vs. Desktopové

Zásadní rozdíly v architektuře běhu, nasazení a režimu správy

Otázka k absolutoriu

1. Serverové DBMS

PostgreSQL, MySQL, MariaDB, MS SQL, Oracle

Samostatný proces (démon / služba) běžící na serveru, naslouchající na síťovém portu (3306, 5432, 1433, 1521). Plná podpora souběžného přístupu, řízení oprávnění a transakcí.

2. Vestavěné (Embedded) DBMS

SQLite, DuckDB

Žádný běžící server ani síťový proces! Kód databázového enginu je přilinkován přímo do aplikace. Celá databáze je uložena v jediném souboru na disku (mobilní appky, IoT, prohlížeče).

3. Desktopové kancelářské DB

MS Access, LibreOffice Base

Kombinace databáze, grafických formulářů a generátoru tiskových sestav v jednom souboru (.accdb). Vhodné pouze pro jednoduchou jedno-uživatelskou evidenci, nevhodné pro web.

Proč nelze provozovat webový e-shop na MS Access?
MS Access má limit velikosti souboru maximálně 2 GB, nemá řádkové zamykání (zamyká celé stránky či soubor), neumí bezpečný souběh stovek webových vláken a nemá ochranu proti poškození souboru při náhlém pádu síťového spojení.
Open-Source pilíře internetu

MySQL vs. MariaDB vs. PostgreSQL vs. SQLite

Srovnání nejrozšířenějších bezplatných databázových platforem

MySQL 8 & MariaDB

  • Zaměření: Nejpopulárnější webové relační databáze (LAMP stack, WordPress, e-shopy).
  • Architektura úložiště: Zásuvné úložné enginy (Storage Engines):
    • InnoDB: Plně ACID, řádkové zámky, cizí klíče, crash recovery (výchozí).
    • MyISAM: Starý rychlý engine bez transakcí a cizích klíčů (dnes nedoporučen).
  • MariaDB: Komunitní fork MySQL po akvizici firmy společností Oracle. Plně kompatibilní, často přináší rychlejší optimalizátor a otevřenější vývoj.

PostgreSQL & SQLite

  • PostgreSQL: Označován za „nejpokročilejší open-source databázi na světě“.
    • Nejstriktnější dodržování standardu ANSI SQL.
    • Silná podpora JSONB (binární indexovaný JSON) a rozšiřitelnost (PostGIS pro mapy a geolokaci, pgvector pro AI).
    • Komplexní analytika a pokročilé window funkce.
  • SQLite: Veřejná doména (Public Domain), nejrozšířenější software na světě (v každém Androidu, iPhonu, prohlížeči Chrome/Firefox). Extrémně spolehlivá a bezúdržbová.

Projektová praxe

Volba technologie pro náš edu_eshop

Proč jsme pro výukový model zvolili právě MySQL 8 / MariaDB

Klíčové důvody volby MySQL / MariaDB

  • InnoDB Storage Engine: Zajišťuje striktní referenční integritu (ON DELETE CASCADE, RESTRICT) a transakční zpracování objednávek.
  • Rodilá podpora JSON: Sloupec product.attributes využívá nativní JSON datový typ pro dynamické parametry zboží (barva, paměť, úhlopříčka).
  • Perfektní čeština: Kódování utf8mb4 s kolací utf8mb4_czech_ci zaručuje bezchybné řazení podle české abecedy (Ch po H).
  • Podpora triggerů a pohledů: Automatická inkrementace category.product_count a souhrnné view v_order_summary.

Kdy bychom volili jiný DBMS?

PostgreSQL: Pokud by e-shop potřeboval vyhledávat nejbližší výdejní místa podle GPS souřadnic zákazníka pomocí prostorových indexů (PostGIS).
SQLite: Pokud bychom pro e-shop vyvíjeli mobilní aplikaci pro iOS/Android, která umožňuje prohlížet košík a historii nákupů v režimu offline.
Oracle RAC / MS SQL: Pokud by e-shop vyrostl na miliardové globální obraty s požadavkem na aktivní multi-datacenter replikaci.

Checklist

Zkouškový checklist k DBMS

  • Vyjmenovat alespoň 5 moderních SŘBD a rozdělit je na Open-Source a Komerční.
  • Vysvětlit zásadní rozdíl mezi Serverovým DBMS (klient-server démon) a Vestavěným DBMS (SQLite).
  • Popsat rozdíl mezi úložnými enginy InnoDB a MyISAM v MySQL.
  • Uvést silné stránky PostgreSQL (pokročilý SQL standard, JSONB, geodata PostGIS).
  • Zargumentovat, proč je MS Access nevhodný pro internetové aplikace (limit 2 GB, zamykání, absence serveru).

Pojmy do slovníku

  • Storage Engine: Softwarový modul v DBMS zodpovědný za čtení a zápis dat na disk (např. InnoDB).
  • Embedded Database: Knihovna přímo volaná aplikací bez síťového soketu (SQLite).
  • MVCC (Multi-Version Concurrency Control): Technika řízení souběhu čtenářů a písařů bez vzájemného blokování.
  • Porty standardních DBMS: MySQL (3306), PostgreSQL (5432), MS SQL (1433), Oracle (1521).
