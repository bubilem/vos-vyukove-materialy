Architektura dotazu

Logické pořadí vyhodnocování SELECT dotazu

Jak databázový engine interně zpracovává zapsaný dotaz

Klíčová otázka absolutoria

Zatímco dotaz píšeme v pořadí SELECT → FROM → WHERE ..., databáze jej vyhodnocuje v úplně jiném logickém pořadí:

1. FROM

Určení zdrojových tabulek a provedení relačních spojení (JOIN).

2. WHERE

Filtrace jednotlivých řádků před jakoukoliv agregací.

3. GROUP BY & HAVING

Seskupení řádků a filtrace agregovaných skupin.

4. SELECT

Projekce sloupců, výpočet výrazů a přiřazení aliasů (AS).

5. ORDER BY

Seřazení výsledné sady řádků (zde již lze použít aliasy ze SELECTu!).

6. LIMIT / OFFSET

Oříznutí počtu vrácených řádků pro klienta.

Proč nelze v klauzuli WHERE použít alias ze SELECTu?
Častá chyba: SELECT price * 1.21 AS cena_s_dph FROM product WHERE cena_s_dph > 1000; zhavaruje! Důvod je právě v pořadí: klauzule WHERE se vyhodnocuje dříve, než klauzule SELECT alias vůbec vytvoří!
Filtrování dat

Klauzule WHERE a vyhledávání

Relační operátory, rozsahy BETWEEN, množiny IN a vzory LIKE

Praktické dotazy nad edu_eshop 
-- 1. Rozsah cen (BETWEEN je včetně krajních mezí!)
SELECT `name`, `price`, `stock_quantity`
FROM `product`
WHERE `price` BETWEEN 500 AND 20000
  AND `active` = TRUE;

-- 2. Množinový výběr stavů
SELECT `id`, `customer_id`, `status`
FROM `orders`
WHERE `status` IN ('paid', 'shipped');

-- 3. Vyhledávání textových vzorů (LIKE)
SELECT `name`, `price`
FROM `product`
WHERE `name` LIKE '%klávesnice%';

Zástupné znaky operátoru LIKE

  • % (procento): Zastupuje libovolný počet znaků (0 až n).
    '%cz' končí na cz, '%phone%' obsahuje phone.
  • _ (podtržítko): Zastupuje právě jeden libovolný znak.
    'A_C' vyhovuje např. 'ABC', 'A1C'.
  • Negace: NOT BETWEEN, NOT IN (...), NOT LIKE '...'.
Výkonnostní past operátoru LIKE '%text'
Pokud zástupný znak % umístíte na začátek vzoru, SŘBD nemůže použít standardní B-stromový index a musí projít celou tabulku (Full Table Scan)!
Záludnosti SQL

Hodnota NULL & Tříhodnotová logika (3VL)

NULL neznamená nulu ani prázdný řetězec, ale „neznámou hodnotu“

Nejčastější chyba studentů

Fatální chyba: sloupec = NULL

V SQL platí tříhodnotová logika: pravda (TRUE), nepravda (FALSE) a neznámo (UNKNOWN).

Výraz NULL = NULL není TRUE, ale UNKNOWN! Klauzule WHERE propustí pouze řádky s výsledkem TRUE, takže dotaz WHERE phone = NULL nikdy nevrátí žádný řádek!

Správný test na NULL
-- Zákazníci bez vyplněného telefonu:
SELECT * FROM `customer_profile`
WHERE `phone` IS NULL;

-- Zákazníci s vyplněným telefonem:
SELECT * FROM `customer_profile`
WHERE `phone` IS NOT NULL;

Užitečné funkce: COALESCE a IFNULL

COALESCE(val1, val2, ...): Vrátí první hodnotu v seznamu, která není NULL.

Ukázka z edu_eshop
SELECT 
  `first_name`, 
  `last_name`,
  COALESCE(`phone`, 'Telefon neuveden') AS kontakt
FROM `customer_profile`;

Řazení a stránkování

Řazení (ORDER BY) a Stránkování (LIMIT)

Jak realizovat katalog produktů e-shopu se stránkováním

Katalog: Nejlevnější produkty na stránce č. 1 
SELECT `id`, `name`, `price`, `stock_quantity`
FROM `product`
WHERE `active` = TRUE
ORDER BY 
  `price` ASC,      -- Primární řazení od nejlevnějšího
  `name` ASC        -- Sekundární řazení při shodě cen
LIMIT 3 OFFSET 0;   -- První 3 položky (stránka 1)

-- Stránka 2: Přeskočit 3, vzít další 3
LIMIT 3 OFFSET 3;   -- Alternativa: LIMIT 3, 3

Pravidla pro řazení a stránkování

  • Výchozí směr: ASC (vzestupně od A do Z, od 0 do 9). DESC (sestupně).
  • Vzorec pro stránkování:
    OFFSET = (číslo_stránky - 1) * počet_na_stránku
  • Deterministické řazení: Pokud řadíte podle sloupce s duplicitními hodnotami (např. kategorie nebo cena), vždy přidejte do ORDER BY jako poslední kritérium id ASC. Jinak se pořadí produktů mezi stránkami může náhodně měnit!

Shrnutí: Základní dotazování DQL

Zásady pro psaní čistých a rychlých dotazů SELECT

1

Nikdy v kódu nepište SELECT *

Vždy jmenujte konkrétní sloupce. Snižuje to síťový přenos, šetří RAM klienta a umožňuje databázi využít pokrývající indexy (Covering Index).

2

Pamatujte na NULL

Pro testování prázdných hodnot vždy používejte operátory IS NULL / IS NOT NULL a funkci COALESCE.

3

Stránkování potřebuje ORDER BY

Klauzule LIMIT bez explicitního ORDER BY vrací řádky v nedeterministickém fyzickém pořadí z disku.
