Kontext a architektura

Evoluce příkazových interpretů: DOS → CMD → PowerShell

Proč pouhý text nestačil a proč Microsoft vytvořil objektově orientovaný shell

Architektura Shellů Text vs. Objekty
Klasický CMD (Příkazový řádek / .bat)
Od roku 1981 (MS-DOS)

Založen na interpretu cmd.exe (nástupce COMMAND.COM). Slouží k jednoduchému spouštění binárek a sekvenčních příkazů:

  • Pouze surový text: Výstup každého programu je obyčejný nestrukturovaný řetězec znaků (ASCII / ANSI).
  • Složité zpracování dat: Chcete-li získat 3. sloupec výstupu, musíte použít krkolomný cyklus for /f "tokens=3".
  • Výhoda: 100% kompatibilita na každém PC s Windows od roku 1993, bleskový start (0 ms režie).
Typické užití dnes:
Rychlé instalační wrappery, spouštěče projektů (start.bat), bleskové síťové testy (ping, tracert).
PowerShell (Objektový shell na .NET)
Od roku 2006 (Jeffrey Snover)

Revoluční architektura postavená přímo na běhovém prostředí .NET Common Language Runtime (CLR):

  • Rourou tečou objekty, ne text: Výstupem příkazu není řádkový text, ale živý .NET objekt s vlastnostmi (Properties) a metodami (Methods).
  • Typová bezpečnost: Žádné parsování mezer a oddělovačů. Na objektu procesu jednoduše zavoláte $p.Kill() nebo $p.WorkingSet64.
  • Cross-platform (PowerShell 7 Core): Běží nativně na Windows, Linuxu i macOS!
Typické užití dnes:
Kompletní administrace Windows a Active Directory, Azure/AWS cloud, automatizace serverů, bezpečnostní audity.

Základy PowerShellu

Anatomie Cmdletů a „Svatá trojice“ objevování

Všechny příkazy mají předvídatelný tvar Sloveso-PodstatnéJméno (Verb-Noun)

Cmdlety Get-Help • Get-Member
Struktura příkazu: Sloveso-Jméno

Microsoft stanovil striktní seznam povolených sloves (lze vypsat pomocí Get-Verb):

  • Get-* – Čtení informací (Get-Process, Get-Service, Get-Disk)
  • Set-* – Změna existujícího nastavení (Set-Date, Set-Service)
  • New-* – Vytvoření nového prostředku (New-Item, New-LocalUser)
  • Start-* / Stop-* – Ovládání životního cyklu služeb a úloh
  • Test-* – Diagnostika vracející True/False (Test-Connection, Test-Path)
Vestavěné aliasy (Linux & CMD přívětivost):
Můžete psát ls nebo dir → spustí se Get-ChildItem.
Můžete psát ps → spustí se Get-Process.
Můžete psát cat nebo type → spustí se Get-Content.
Svatá trojice pro administrátora

Nemusíte si pamatovat parametry zpaměti. Tyto 3 příkazy vám řeknou vše:

powershell • 3 klíčové diagnostické příkazy 
# 1. Hledání příkazu podle klíčového slova:
PS> Get-Command *firewall*

# 2. Manuál a příklady použití (včetně přepínače -Examples):
PS> Get-Help Get-Process -Online
PS> Get-Help Stop-Service -Examples

# 3. Zjištění, jaké vlastnosti a metody objekt má (NEJDŮLEŽITĚJŠÍ!):
PS> Get-Process | Get-Member
Příkaz Get-Member vám ukáže všechna skrytá data objektu
Srdce PowerShellu

Objektová roura (Pipeline): Filtrování, řazení a export

Proč je objektová roura stonásobně spolehlivější než textový parser v CMD či Bashi

Pipeline | Where-Object • Select-Object
Základní stavební kameny roury

Zatímco v CMD se musíte modlit, aby výstup měl stejný počet mezer, v PowerShellu filtrujete přímo vlastnosti objektu:

  • Where-Object (alias ?): Filtruje objekty podle podmínky.
    Get-Service | Where-Object Status -eq 'Running'
  • Select-Object (alias select): Vybere jen požadované sloupce/vlastnosti nebo omezí počet řádků (-First 5).
  • Sort-Object (alias sort): Seřadí objekty podle zvoleného atributu (např. sestupně podle spotřeby RAM).
  • Out-GridView (alias ogv): Okamžitě otevře interaktivní grafické okno s filtrováním a vyhledáváním!
Filozofie PowerShellu:
Filtrujte vlevo, formátujte vpravo (Filter Left, Format Right). Data zužujte co nejdříve v rouně, tabulku či CSV exportujte až na samém konci.
Praktické One-Linery k vyzkoušení
powershell • Ukázky praktického řetězení v rouně 
# 1. Najít 5 procesů, které žerou nejvíce operační paměti (RAM):
PS> Get-Process |
    Sort-Object -Property WS -Descending |
    Select-Object -First 5 -Property Name, Id, @{Name="RAM_MB"; Expression={[math]::round($_.WS/1MB, 1)}}

# 2. Všechny zastavené automatické služby a export do CSV souboru:
PS> Get-Service |
    Where-Object { $_.StartType -eq 'Automatic' -and $_.Status -eq 'Stopped' } |
    Export-Csv -Path ".\ChybneSluzby.csv" -NoTypeInformation -Encoding utf8

# 3. Zobrazení všech síťových spojení v interaktivním GUI okně:
PS> Get-NetTCPConnection | Out-GridView
Tradiční Windows skriptování

Dávkový soubor (.bat / .cmd): Proměnné a výpisy

Základní syntaxe příkazového skriptu, vstupy od uživatele a systémové proměnné

Soubory .BAT SET • %VAR% • %1
Pravidla syntaxe dávkového skriptu
Základní kostra
  • @echo off – Povinný první řádek. Zabrání tomu, aby interpret tiskl na obrazovku každý vykonávaný řádek kódu.
  • echo Text – Výpis zprávy do konzole. Prázdný řádek vypíšete jako echo.
  • rem nebo :: – Komentář (interpret jej ignoruje).
  • pause – Pozastaví běh a čeká na stisk libovolné klávesy (*„Stiskněte libovolnou klávesu...“*). Zabrání okamžitému zavření okna po dokončení!
  • exit /b 0 – Ukončí skript a vrátí kód chyby (Exit Code).
Důležité speciální proměnné:
%~dp0 – Absolutní cesta ke složce, kde skript fyzicky leží (včetně zpětného lomítka).
%1 až %9 – Parametry předané z příkazové řádky (např. skript.bat soubor.txt).
%ERRORLEVEL% – Návratový kód posledního spuštěného příkazu (0 = úspěch).
Příklad: skript_pozdrav.bat
batch • Práce s proměnnými a vstupem uživatele 
@echo off
:: Nastavení kódování UTF-8 pro správnou českou diakritiku v CMD:
chcp 65001 >nul

:: Definice proměnné:
set AUTOR=Jan Novak
set VERZE=1.0

echo ==========================================
echo Spoustim skript verze %VERZE% od %AUTOR%
echo Aktualni datum a cas: %DATE% %TIME%
echo Slozka skriptu: %~dp0
echo ==========================================
echo.

:: Vstup od uživatele přes přepínač /p :
set /p JMENO=Zadejte sve jmeno: 
echo Vitej v terminalu Windows, %JMENO%!

:: Matematické výpočty přes přepínač /a :
set /a VYSLEDEK=10 * 5 + 2
echo Matematicky vypocet (10 * 5 + 2) = %VYSLEDEK%

pause
Řízení toku v dávkách

Podmínky (IF) a Cykly (FOR) v dávkovém souboru

Větvení podle hodnot, testování existence souborů a procházení seznamů

Řízení toku IF / ELSE • FOR %%i
Podmínky: IF / ELSE v dávce

Závorka ( musí být vždy na stejném řádku jako příkaz if a else:

batch • Ukázky větvení IF 
:: 1. Porovnání textových řetězců (doporučeno dát do uvozovek):
if "%ODPOVED%"=="ano" (
    echo Zvolil jste pokracovat.
) else (
    echo Operace byla zrusena.
)

:: 2. Test existence souboru či složky na disku:
if exist "C:\zaloha\data.txt" (
    echo Soubor jiz existuje!
) else (
    echo Soubor nenalezen, vytvarim...
)

:: 3. Test návratového kódu předchozího příkazu:
ping -n 1 8.8.8.8 >nul
if %ERRORLEVEL% equ 0 (
    echo [OK] Internetove pripojeni funguje.
) else (
    echo [CHYBA] Internet neni dostupny!
)
Cykly: FOR ve skriptu .bat

Pozor: V souboru .bat se proměnná píše se dvěma procenty (%%i), v příkazovém řádku přímo jen s jedním (%i):

batch • 3 podoby cyklu FOR 
:: A. Číselný cyklus (od, krok, do):
for /L %%i in (1, 1, 5) do (
    echo Krok cislo %%i
)

:: B. Procházení souborů s příponou .txt v adresáři:
for %%f in (*.txt) do (
    echo Zpracovavam textak: %%f
)

:: C. Parsování obsahu souboru po řádcích (přepínač /F):
for /F "tokens=1,2 delims=," %%a in (uzivatele.csv) do (
    echo Uzivatel: %%a, Oddeleni: %%b
)
Moderní skriptování

Skripty v PowerShellu (.ps1): Proměnné, Podmínky & Cykly

Čistá syntaxe inspirovaná C#, bezpečnostní politika ExecutionPolicy a datové struktury

PowerShell .ps1 foreach • hashtables
Execution Policy: První překážka
Bezpečnostní štít

Windows ve výchozím stavu zakazují spouštění stažených .ps1 skriptů dvojklikem myši, aby chránily uživatele před malwarem.

powershell • Povolení spouštění skriptů v konzoli 
# Povolení spouštění pro aktuálního uživatele (bezpečné):
PS> Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned

# Jednorázové spuštění skriptu bez trvalé změny systému:
PS> powershell.exe -ExecutionPolicy Bypass -File .\skript.ps1
Podmínkové operátory v PowerShellu:
PowerShell nepoužívá znaky > ani < (protože ty slouží pro přesměrování textu do souboru!). Používá zkratky:
-eq (rovno), -ne (nerovno), -gt (větší než), -lt (menší než), -like (maska s *), -match (RegEx).
Příklad: komplexni_skript.ps1
powershell • Pole, asociativní pole, cyklus a podmínka 
# 1. Definice proměnných a typovaného pole:
$Servery = @("web01", "db01", "backup01")

# 2. Asociativní pole (Hashtable / Klíč = Hodnota):
$Konfigurace = @{
    Port    = 8080
    Timeout = 5
    Povoleno= $true
}

# 3. Cyklus foreach s podmínkou:
foreach ($srv in $Servery) {
    $stav = Test-Connection -ComputerName $srv -Count 1 -Quiet
    
    if ($stav -eq $true) {
        Write-Host "[ONLINE] Server $srv odpovida." -ForegroundColor Green
    } else {
        Write-Warning "[OFFLINE] Server $srv je nedostupny!"
    }
}

Reálná systémová praxe

Jak propojit .bat s PowerShellem a automatizovat úlohy

Využití .bat jako spouštěče, který obejde ExecutionPolicy a předá parametry

Integrace Wrapper .bat • Task Scheduler
Univerzální spouštěč: spustit.bat

Zákazník nebo koncový uživatel neumí spustit .ps1 přes konzoli. Vytvořte mu jednoduchý klikací .bat wrapper:

batch • Spouštěč PowerShell skriptu bez omezení politiky 
@echo off
title Spoustec zalohovaciho systemu

:: Spuštění .ps1 skriptu ze stejné složky se všemi předanými parametry:
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "%~dp0zaloha.ps1" %*

:: Kontrola, zda PowerShell skončil úspěšně:
if %ERRORLEVEL% neq 0 (
    echo [CHYBA] PowerShell skript selhal s kodem %ERRORLEVEL%!
    pause
    exit /b %ERRORLEVEL%
)

echo [HOTOVO] Vse uspesne probehlo.
timeout /t 3 >nul
Plánovač úloh (Task Scheduler)

Jak nastavit automatický noční běh skriptu v Plánovači úloh Windows:

  • Program/skript: powershell.exe (nebo celá cesta C:\Windows\System32\WindowsPowerShell\v1.0\powershell.exe)
  • Přidat argumenty:
    -NonInteractive -NoProfile -ExecutionPolicy Bypass -File "C:\Skripty\AutoZaloha.ps1"
  • Spustit v: C:\Skripty
  • Oprávnění: Zaškrtněte „Spouštět nezávisle na přihlášení uživatele“ a „Spustit s nejvyššími oprávněními“ (pro přístup k systémovým souborům).
Inženýrský tip: Výpis do Windows Event Logu
V PowerShellu můžete zapsat výsledek zálohy přímo do Prohlížeče událostí Windows:
Write-EventLog -LogName Application -Source "MojeZaloha" -EventId 100 -EntryType Information -Message "Zaloha dokoncena."

Hands-on Lab Cheat Sheet
Cvičení 1: Automatická rotace záloh s zipem PowerShell

Zazipujte složku s daty a přidejte do názvu aktuální datum:

powershell 
$dnes = Get-Date -Format "yyyy-MM-dd_HH-mm"
Compress-Archive -Path "C:\Data" -DestinationPath "D:\Zalohy\Data_$dnes.zip" -Force
Cvičení 2: Interaktivní textové menu v dávce Batch (.bat)

Využití vestavěného příkazu choice pro volbu z menu:

batch 
choice /c 123 /m "Zvolte: 1=Ping brany, 2=Vypis IP, 3=Konec"
if errorlevel 3 exit /b
if errorlevel 2 ipconfig & pause & exit /b
if errorlevel 1 ping 192.168.1.1 & pause
Cvičení 3: Hromadné čištění logů starších 30 dní PowerShell

Bezpečné smazání starých log souborů pomocí pipeline:

powershell 
Get-ChildItem -Path "C:\Logs" -Filter "*.log" |
Where-Object { $_.LastWriteTime -lt (Get-Date).AddDays(-30) } |
Remove-Item -WhatIf  # Odeberte -WhatIf pro skutecne smazani!

Slovník pojmů • PowerShell a dávkový skripting

Cmdlet PowerShell
Odlehčený interní příkaz (.NET třída)
Základní příkaz v PowerShellu s pevnou syntaxí Sloveso-PodstatnéJméno (např. Get-Process). Vrací přímo strukturované objekty.
Pipeline (Roura) Mechanismus
Zřetězení příkazů znakem |
V PowerShellu předává živé .NET objekty se zachováním jejich typů a atributů, na rozdíl od Unix/CMD roury, kde teče pouze surový text.
ExecutionPolicy Bezpečnost
Zásada spouštění skriptů
Bezpečnostní nastavení Windows, které určuje, zda je povoleno spouštět .ps1 skripty (Restricted, RemoteSigned, Unrestricted, Bypass).
.BAT / .CMD Dávkový soubor
Příkazový skript interpretu CMD.EXE
Tradiční skriptovací soubor Windows s kořeny v MS-DOSu. Zpracovává příkazy řádek po řádku jako textové příkazy.
Hashtable Struktura
Asociativní pole (Klíč → Hodnota)
Klíčová datová struktura v PowerShellu zapisovaná jako @{ Klic = "Hodnota" }. Umožňuje bleskové vyhledávání a předávání parametrů (Splatting).
%ERRORLEVEL% Kód chyby
Návratový stav posledního procesu
Globální systémová proměnná v CMD. Hodnota 0 značí úspěch, jakékoliv jiné číslo (často 1 nebo záporná čísla) značí chybu.
WMI / CIM Windows API
Windows Management Instrumentation
Standardizované rozhraní pro dotazování na stav hardwaru (disky, teploty, BIOS), operačního systému i běžících aplikací přes Get-CimInstance.
%~dp0 CMD Modifikátor
Drive & Path nultého argumentu
Speciální operátor v souborech .bat, který vrátí absolutní cestu ke složce, kde se skript právě nachází, nezávisle na aktuální pracovní složce.
