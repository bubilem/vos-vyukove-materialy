Kruhy oprávnění (Privilege Rings)

Klíčový koncept
Ring 0 • Kernel Mode Plná práva (Jádro, Ovladače)
Ring 1 • Ovladače (Historické / Nepoužívá se) Nevyužito
Ring 2 • OS Služby (Historické / Nepoužívá se) Nevyužito
Ring 3 • User Mode Omezená práva (Aplikace)

Privilegované instrukce CPU

Pokud se aplikace v Ring 3 pokusí spustit kteroukoli z těchto instrukcí, procesor okamžitě vyvolá hardwarovou výjimku General Protection Fault (#GP) a jádro proces ukončí:

  • HLT: Zastavení procesoru do úsporného stavu.
  • CLI / STI: Zákaz nebo povolení hardwarových přerušení.
  • LIDT / LGDT: Změna tabulky přerušení (IDT) nebo deskriptorů.
  • MOV CR0, EAX: Změna řídicích registrů (vypnutí stránkování či ochrany zápisu).

Otázka u zkoušky

Evoluce systémových volání na x86

  • Historická metoda: INT 0x80 (Linux) / INT 0x2E (Windows): Vyvolání softwarového přerušení přes tabulku IDT. Uložení mnoha registrů na zásobník – režie cca 1000 taktů procesoru.
  • Moderní x86_64: Instrukce SYSCALL / SYSRET: Rychlý skok pomocí speciálních MSR registrů (Model-Specific Registers). Režie klesla na desítky taktů!
  • Procesor v jediném taktu načte novou hodnotu čítače instrukcí (RIP) a přepne hodnotu ukazatele zásobníku (RSP) na jádrový zásobník (Kernel Stack) daného vlákna.

Bezpečnostní bariéra: Oddělení zásobníků

Každé vlákno v systému má dva zásobníky (Stacks):

  • User Stack: V paměti procesu, plně pod kontrolou aplikace.
  • Kernel Stack: V privilegované paměti jádra. Při přechodu do Ring 0 se okamžitě přepne zásobník. Aplikace nemůže podvrhnout návratovou adresu jádru přetečením svého zásobníku!
Architektura ARM64

Úrovně výjimek v procesorech ARM (AArch64)

Moderní hierarchie: od aplikací přes OS a hypervizor až po Secure World

ARM64 • EL0-EL3

Čtyři úrovně Exception Levels (EL)

  • EL0 (User): Běžné aplikace (ekvivalent Ring 3 na x86).
  • EL1 (Kernel): Operační systém (Linux jádro, Windows NT, macOS XNU).
  • EL2 (Hypervisor): Virtualizace (KVM, Xen, Apple Hypervisor). Spravuje virtuální stroje.
  • EL3 (Secure Monitor / Firmware): Zabezpečený svět (TrustZone), správa kryptografických klíčů a bezpečný start (Secure Boot).

Přechod mezi úrovněmi na ARM

  • Aplikace volá instrukci SVC (Supervisor Call) pro přechod z EL0 do EL1.
  • OS volá instrukci HVC (Hypervisor Call) pro přechod z EL1 do EL2.
  • Hypervizor volá instrukci SMC (Secure Monitor Call) pro přechod do EL3 (TrustZone).
  • Vyšší úroveň má vždy plnou kontrolu nad všemi nižšími úrovněmi.

nasm • Ukázka nízkoúrovňového syscallu na x86_64 
; Volání zápisu na konzoli (sys_write) v čistém assembleru
mov rax, 1          ; Číslo syscallu: sys_write v Linuxu
mov rdi, 1          ; Deskriptor 1 = stdout
mov rsi, msg        ; Adresa textového řetězce
mov rdx, 14         ; Délka řetězce
syscall             ; Skok do Ring 0 (přepne CPU na adresu v IA32_LSTAR)

mov rax, 60         ; Číslo syscallu: sys_exit
xor rdi, rdi        ; Návratový kód 0
syscall

Absolutorium

1. Ring 0 vs. Ring 3

Schopnost přesně vysvětlit rozdíl v oprávněních procesoru (přístup k I/O portům, řídicím registrům CR0-CR4 a paměti označené příznakem Supervisor).

2. Instrukce SYSCALL

Popis mechanismu skoku z User Mode do Kernel Mode, přepnutí na bezpečný Kernel Stack a návrat pomocí SYSRET.

3. ARM Exception Levels

Znalost vrstev EL0 (User), EL1 (OS Kernel), EL2 (Hypervisor) a EL3 (Secure Monitor / TrustZone).
