# Webové technologie

## Cíl předmětu
Cílem předmětu je studenta seznámit s principy webové komunikace a tvorbou webových prezentací. Student bude seznámen se současnými moderními webovými technologiemi a řešeními.

## Anotace předmětu
Předmět Webové technologie je volitelným předmětem absolutoria a skládá se ze tří modulů s následujícím obsahem:

- Modul WEB10 je zaměřen na principy webových technologií
- Modul WEB20 je zaměřen na strukturu webových technologií
- Modul WEB30 je zaměřen na příklady webových technologií

Výuka je realizována formou přednášek, konzultací a cvičení s podporou PC

## Okruhy k absolutoriu

1. **Architektura webu a webová komunikace**: klient-server architektura, webový klient, webový server, statický a dynamický web
2. **Protokol HTTP a síťová komunikace**: princip protokolu HTTP/HTTPS, metody požadavků, stavové kódy, hlavičky, bezpečnost a SSL/TLS
3. **Vývoj, standardy a principy jazyka HTML**: historie, W3C, WHATWG, přechod od XHTML k HTML5, sémantika, validace
4. **Základní struktura a syntaxe HTML**: kostra dokumentu, značky, atributy, práce s textem, hypertextové odkazy, seznamy a tabulky
5. **HTML5 multimédia a formuláře**: formulářové prvky a nové typy vstupů, klientská validace, audio a video na webu, canvas
6. **Moderní webové technologie a cloudové služby**: webhosting, domény, CDN, služby a API pro webdesignéry
7. **Struktura webové stránky a DOM**: sémantické členění stránky (header, nav, main, article, section, footer), objektový model dokumentu
8. **Kaskádové styly (CSS)**: způsoby začlenění stylů, syntaxe, princip kaskády, dědičnost a specificita, CSS reset
9. **CSS selektory a pseudotřídy**: typové selektory, třídy, ID, atributové selektory, kombinátory, pseudotřídy a pseudoelementy
10. **Box model a rozměry v CSS**: model krabičky (content, padding, border, margin), box-sizing, vlastnost display
11. **Metody tvorby layoutu v CSS**: plovoucí prvky (float), CSS pozicování (static, relative, absolute, fixed, sticky), Flexbox, CSS Grid
12. **CSS preprocesory**: princip preprocesingu, syntaxe a možnosti preprocesorů Sass a Less (proměnné, vnořování, mixiny, dědičnost)
13. **Formáty pro syndikaci a výměnu dat**: jazyk XML, struktura, syndikace obsahu, srovnání a využití RSS a Atom
14. **Návrh GUI a ergonomie webu**: zásady použitelnosti (usability), ergonomie ovládacích prvků, informační architektura, wireframy
15. **Vizuální prvky webu**: webová typografie, hierarchie a čitelnost textu, webové fonty (@font-face), ikonové sady a SVG
16. **Responzivní webdesign (RWD)**: viewport, Media Queries, fluidní rozvržení, responzivní multimédia, přístup Mobile-First
17. **Přístupnost webových stránek**: význam a principy přístupnosti, standardy WCAG, Section 508, WAI-ARIA, asistenční technologie
18. **Optimalizace a výkonnost webových stránek**: rychlost načítání, optimalizace obrázků a assetů, minifikace, caching, Core Web Vitals
19. **SEO a SEM**: optimalizace pro vyhledávače (on-page a off-page faktory), sitemaps, robots.txt, význam metadat, základy SEM
20. **Vývoj klientských technologií a interaktivita**: historie a ústup pluginů (Adobe Flash, Java applety), moderní standardy a bezpečnost
